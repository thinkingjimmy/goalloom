# Goalloom · MVP验收用例

v0.3.1 · 2026-09-21。**全部待执行。** 本表为规格，不是测试通过报告。记录实际构建、OS / CPU、驱动、测试数据、执行方式与结果。

Electron已确认；单主位置、独立完成状态、只读历史和可追踪顺延为共同不变量。D06基数确认后再补对应关系专用场景。除E09另列公开发布门槛，以下均为P0。

## A. 录入、看板与移动

| ID | 场景 | 验收 |
| --- | --- | --- |
| A01 | 首次断网启动 | 无登录阻断，进入当前五列，明确默认顺延设置 |
| A02 | 本周新建并重启 | 仅一ID、一主位置，创建事件和数据都保留 |
| A03 | 中文IME组合输入时Enter | 只选词，不提前提交或重复创建 |
| A04 | Week移到Today | ID、关联、状态、due_date不变，只有Today主卡片；记录移动而非延期 |
| A05 | 月目标拆解下一步 | 新子项ID；父目标留原位；条目 / 位置 / 关系 / 初始事件原子成功 |
| A06 | 空列落点 / 列内排序 | 重启顺序正确；同周期排序不制造顺延事件 |
| A07 | 拖动中Esc | 数据库 / 事件无变化，视图恢复 |
| A08 | 落点保存失败 | 位置与历史全回滚，报错并保留用户输入 |
| A09 | 窄窗口 / 抽屉 | 所有列可达，文字和控件可用 |
| A10 | 完成后重开 | 同一条目，事件保留真实先后，独立完成时间语义一致 |

## B. 关联与状态独立

| ID | 场景 | 验收 |
| --- | --- | --- |

| B02 | 重复关联同一父子对 | 无重复有效边 |
| B03 | A→B→C后C→A或A→A | 拒绝，原图不变 |

| B07 | 解除关系与跨列移动 | 解除不删任务；移动不解除关系；都不传播完成状态 |

## G. 自动顺延、反馈与撤销

| ID | 场景 | 验收 |
| --- | --- | --- |
| G01 | 首次默认设置 | day自动；week/month手动可切自动；cycle固定手动；Later不适用 |
| G02 | Today改手动，跨日 | 旧任务保留旧placement，当前往期入口可见，无自动事件 |
| G03 | 本周 / 本月开启自动后跨界 | 各自符合条件任务移入新同类当前周期，不改变其他尺度 |
| G04 | 完成 / 取消 / 归档 / 删除的旧项 | 自动流程全部排除；无新承诺或重复条目 |
| G05 | 有due_date和父子关联的项自动顺延 | 截止日、状态、关系不变；父子不级联移动 |
| G06 | 月设置10月15日开启，既有9月积压 | 不立即移9月；10月任务11月可自动；设置关闭不撤回已发生顺延 |
| G07 | 9月关闭到11月且月策略此前已启用 | 只记实际9→11一跳和真实执行时间；10月无虚假顺延 / 主计划 |
| G08 | 多来源批次进入已有当前列 | 现有顺序不变；新项按来源 / 原顺序追加；摘要与逐项来源正确 |
| G09 | 批次成功 / 失败 | 成功才显示计数、查看、撤销；失败位置 / 事件全回滚，无成功提示 |
| G10 | 顺延提交成功后响应丢失并重试 | 返回原结果或核对实际已完成，无第二次移动 / 事件 |
| G11 | 批次中所有任务未再修改，撤销 | 恢复原位置，追加反向事件、保留原事件，内容 / due_date不变 |
| G12 | 部分任务后续编辑 / 完成 / 删除 / 再次移动 | 撤销跳过冲突项并报告，其他符合项可恢复，不覆写新状态 |
| G13 | Today保持自动，撤销后立即前台 / 重启 | 当前周期hold保留；任务在今天列往期入口可见且可手动安排，不马上自动搬回，也不从当前工作视图消失 |
| G14 | 撤销后进入新周期 / 用户手动移动 | 按新周期策略处理；手动移位清除旧hold，不永久冻结任务 |
| G15 | 对同一事件重复撤销 / 查看旧批次再撤销 | 至多一次反向修改；可撤销旧批次以执行时当前周期设置hold，不立即自动搬回 |
| G16 | 顺延 / 撤销任意写入步骤故障 | 当前位置、事件、批次结果一致，无只改位置或只写历史 |
| G17 | 手动完成与自动顺延并发 | 串行实际顺序；先完成不再顺延，先顺延后完成保留真实两事件 |
| G18 | Month→Week→Today / 同期排序 / 跨多月一跳 | 前两者不算延期，后一项只算一次实际顺延；不新增进度计算 |
| G19 | 恰好周期结束边界完成 / 系统时钟回拨 | 边界事件归新日期；同时间按seq稳定；时钟异常不伪造历史或双重顺延 |
| G20 | 长期未完成持续多个周期 | 仍可找回与手动决定；无自动归档 / 删除，原来源与真实事件可追溯 |
