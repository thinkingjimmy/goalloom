# Goalloom · 产品需求

v0.6.1 · 2026-09-22。产品规则在本文件维护，工程与验收见 [TODO](TODO.md)。

## 1. 产品与首版范围

**把长期方向拆成行动，再安排到合适的时间。** 面向个人，不要求学习企业 OKR 流程。

首版为 **Electron 的 macOS / Windows 本地桌面**，采用 React、TypeScript、Vite、shadcn/ui、Tailwind CSS、Hugeicons 和 SQLite。核心是五列、录入编辑、拖拽排序、实体关联、搜索、历史、未完成事项处理与可靠备份恢复。

完成、重开或取消只影响自己，不汇总百分比或联动父子状态；引用展示同一实体的新标题 / 状态。目标和任务统一为条目，不设类型选择器或用户自定义颜色；尚未拆解的目标也可独立存在。

**后置：** 有任务数据后的日历规则修改、SVG 连线、进度 / KR、重复任务、提醒、普通分类标签、系统全局快速录入、通用批量管理、未来排期、完整复盘 / 内容版本、Markdown 导出、自动更新、托盘和毛玻璃。账号、云同步、Web / 移动端、团队、AI、日历集成和计费另行立项。

## 2. 看板、时间与条目

### 2.1 首次配置与固定日历

| 固定列名，从左到右 | 含义 | 周期结束后默认 | 首版设置 |
| --- | --- | --- | --- |
| Later | 尚未承诺时间 | 不处理 | 无周期、无顺延策略 |
| 3个月 | 自定义目标周期，内部称 cycle | 手动安排 | 初始参数见 D07；顺延固定手动 |
| 本月 | 当前自然月 | 手动安排 | 可开启自动顺延 |
| 本周 | 当前周 | 手动安排 | 初次默认周一，可选周起始日；可开启自动顺延 |
| 今天 | 当前日 | 自动顺延至新的当天 | 可改手动顺延 |

「周期」泛指四种有日期的区间；界面统一用「3个月」，不等同自然季度。**首次启动先显示配置页**，集中展示工作区时区、周起始日和 cycle 起点 / 当前起止范围；时区默认读取系统 IANA 值，检测失败须手选。页面说明「确认后首版不能直接修改当前工作区日历；重新配置需先备份并重置」，用户点击「确认并开始」才保存并锁定配置、进入看板。未确认可修改或退出，所有创建入口（含快捷键和示例导入）均不可写入；确认动作即锁定时刻，创建任务不改变配置。日界、截止提示与完成 / 取消日期分组按工作区时区，历史使用固定边界。

**D07 候选初始参数：** 首次以工作区今天为锚点，可自选不晚于今天的起点，以固定 3 个日历月推导覆盖今天的一轮；例如 `[2026-09-21, 2026-12-21)`，结束日不含在内。原锚点加 `3n` 月、月底截断，避免逐轮漂移。固定时长与起点允许范围在 M0 确认。月 / 周可以跨 cycle，关联不强制日期包含。

**确认后的日历固定，设置页只读展示并提供「重置工作区」入口（§6）。** 删除或撤销全部任务不解锁；重置后返回首次配置页，旧工作区的数据与历史保存在保护备份。系统时区变化只提示、不自动跟随；同一 IANA 时区的夏令时照常生效，不等于固定 UTC 偏移。日常顺延策略仍可随时修改。

整库备份 / JSON 恢复采用源工作区日历并保留其历史；首次配置页也可选择此路径，恢复预览须明确确认源日历。重置是另一个有保护备份和最终确认的整库操作，不是清空回收站或绕过日历锁的隐藏入口。

### 2.2 唯一位置与录入

**每项只有一个 ID、一份状态、一个主位置。** 本周移到今天后，当前本周列既无任务卡片，也无只读引用卡片；只有搜索、详情和历史模式展示引用。往期入口是唯一旧位置的操作投影，不是当前周期副本。移动保留内容、状态、截止日和关联；拆解创建新 ID 和关系，父项留原位，不要求走完五列。

每个当前列可添加。应用内 Cmd/Ctrl+N 进入聚焦的可编辑列，无列焦点或聚焦历史列则落 Later，并显示目标列。标题去空白后必填，同名不合并；标题 Enter 提交、Esc 取消。说明为多行纯文本，Enter 换行、Cmd/Ctrl+Enter 保存；提交避开 IME 组合输入，关闭未保存说明先提示。

`due_date` 可选且独立，移动 / 顺延不自动修改。只有真实截止日已过才显示截止逾期。首版不能排到下周 / 下月：周日晚规划下周需先放 Later，或等周一安排；未来截止日不等于未来排期，界面明确说明限制。

### 2.3 状态、视图、还原与恢复

应用工具栏「视图」菜单和命令面板提供「看板、已完成、已取消、归档、回收站」，设置另有入口，均不增加第六列。普通搜索覆盖未删除条目的标题 / 说明，包括曾安排到历史周期的条目、已完成、已取消及归档，标明状态 / 当前位置；已删除项仅在回收站搜索。

**术语：** 回收站把某条目重新放回可用数据叫「还原」（restoreItem）；用备份 / JSON 替换整个本地工作区叫「恢复」（restoreWorkspace）。解除归档、重新打开和撤销使用各自名称。

| 状态 / 操作 | 当前列与列表 | 返回路径 |
| --- | --- | --- |
| 待办 todo | 未归档 / 删除且属当前周期时在对应列；Later 待办直接显示；旧周期见往期入口 | 正常编辑 / 安排 |
| 完成 done | 本位置所在列的已完成折叠区，Later 同样适用；旧周期不混入当前列 | 已完成或历史详情可重开 |
| 取消 cancelled | 表示不再做，从当前列 / 往期入口移出，不进入完成折叠区 | 已取消列表可重新打开 |
| 归档 | 三种状态均可归档；不改状态、计划或关系，从活跃列 / 往期入口隐藏 | 归档列表解除归档 |
| 删除 | 任意状态软删除；保留状态 / 位置 / 历史身份，相关关系失效，从普通视图隐藏 | 回收站按删除日期查看 / 搜索 / 还原，包含 Later |

已完成列表只列未删除且当前 done 的项，按最近真实 `completed_at` 分组；已取消列表只列未删除且当前 cancelled 的项，按最近真实 `cancelled_at` 分组。两者包含归档项并标注；同组按对应时间倒序，再按 ID 稳定排序。取消 / 完成时间仅对应当前状态，重开后清空相应字段，原事件保留，再取消记录新的实际时间。来源旧数据没有可靠时间时归入「日期未记录」，不用修改时间猜测。

状态、归档、删除是独立维度。解除归档不等于重开；还原保留原归档标记、状态和位置。还原 / 解除归档 / 重开不暗中调期，旧周期 todo 可重新进入往期入口，随后符合策略的 reconcile 才单独顺延。还原重检关系有效性与基数，跳过非法边并提示。**还原单条目不设置或解除整库恢复暂停**；工作区原已暂停则保持暂停。

首版无逐条彻底删除、单独清空回收站或定期清除；§6 的显式整库重置另有保护流程。软删除内容仍存在于本地数据 / 备份，不等于擦除。解除关系不删除条目，归档不解除关系，删除不级联删除上下级。

### 2.4 交互、提示与撤销

轻量列表与弱分隔；列宽建议 260–340px，各列纵向滚动，窄窗口横向导航并可跳到今天，详情用侧边抽屉。提供拖拽及「移动到…」键盘替代、空列落点、边缘滚动、Esc 取消和失败回滚；拖到卡片默认排序，不暗中关联。支持浅色 / 深色 / 系统主题、可见焦点、非颜色提示、减少动效与 Cmd/Ctrl+K 搜索。

**用户撤销栈范围如下，只有成功且实际改变数据的操作入栈。** 一个复合操作只占一步，提示不堆叠抢焦点。

| 操作 | 本会话撤销栈 | 成功反馈 |
| --- | --- | --- |
| 创建（含「拆解下一步」的创建＋关联） | 入栈 | 新条目直接出现，不弹 Toast |
| 跨列 / 跨期移动、完成、重开、取消、删除 | 入栈 | 单一可更新 Toast＋撤销 |
| 关联、解除、换父、归档、解除归档、回收站还原 | 入栈 | 同一 Toast＋撤销 |
| 列内排序 | 入栈 | 不弹 Toast |
| 标题 / 说明 / 截止日编辑、设置变更、首次配置 | 不入应用栈 | 使用编辑器 / 保存反馈 |
| 自动顺延、备份 / JSON 恢复、重置工作区 | 不入用户栈 | 顺延有独立批次撤销；整库操作另行确认 |

非编辑焦点下 Cmd/Ctrl+Z 或命令面板「撤销上一步」处理最近一项；文本框 / contenteditable / IME 内保留文本撤销。栈仅本会话有效，系统批次不挤入用户栈；整库恢复或重置成功清空旧栈和 Toast。取消对话框 / 无数据变化 / 重复提交不产生额外栈项。

**确定冲突时，不逆转任何数据，提示「该操作已有后续修改，已跳过」，仅将该项移出快捷栈；本次按键到此结束，下次按键才处理下一项。** 原操作与历史不删除，不标记为已撤销。保存失败或结果未知不是冲突：保留栈项，先核对结果 / 重试，不能丢掉仍可能有效的撤销。

撤销创建将仍可安全逆转的新条目软删除，保留历史身份；拆解同时解除本次创建的边，保留原父项。撤销关联 / 解除 / 换父须重新检查端点、防环与基数，复合步骤整体逆转或整体不动，不覆盖后续关系。撤销重开还原先前状态及其原有 completed_at / cancelled_at（未知仍未知），另记真实撤销时刻；其他状态 / 可见性操作同样只逆转自身字段。任何撤销回到旧周期 todo，无论手动 / 自动策略均按 §5 落盘 hold。

参考：[多列看板](references/01-time-board.png) · [目标关联](references/02-goal-links.png)。仅借鉴布局 / 交互，不复制原品牌、真实任务或平台假按钮。

## 3. 关联

条目上的「关联到…」选择其**上级**；目标详情的下级区域提供**「关联已有条目为下级」**。两入口都建立 parent→child 的同一种关系，不复制任务、不改变位置 / 状态。**已归档条目可作为任一端点**，两个方向的选择器均可搜索并标「已归档」，建立关系不解除归档或改变状态 / 位置。已有关系去重；拒绝不存在 / 已删除端点、自关联和循环，单父方案遇到其他父节点先显示换父确认，再原子替换；多父方案追加关系。取消操作不写入。

**D06 基数待定：** 单父树或多父 DAG。卡片只显示直接上级「关联标记」：单父最多一个；多父最多两个，其余 `+N`。详情分开展示上下级和活动，路径去重限界。允许跳级及同列关联，改名通过真实 ID 更新引用。

颜色使用**八组固定语义色板**，每组各有浅色 / 深色的背景、文字、边框 token；固定哈希把被引用 ID 映射到0–7索引，同 ID 跨主题保持同索引。允许颜色碰撞，不把颜色当关系身份；不自由生成色相、不存自定义色。主题、禁用 / 选中 / 高对比度状态测试文字与控件对比度，名称和状态不能只靠颜色。

「拆解下一步」建议3个月→本月→本周→今天，Later / 今天默认同列，可改列；新条目 / 位置 / 关系同事务。删除先预览关系影响，还原只尝试本次删除导致失效的合法关系，不重新启用先前主动解除的边。

首版必须有标记、定位、选中高亮。SVG 连线安排为 M4 之后可选，不作首发门槛；仅连可见当前端点，滚动 / 缩放 / 抽屉变化重算，屏外提示，历史端点不接当前图。

## 4. 历史：回看不改变现在

除 Later 外，按列独立翻阅过去 / 返回当前，不联动其他列；历史行只读，不直接添加 / 勾选 / 拖放，点击打开标明「当前条目」的详情，已删除项转回收站详情。首版不向未来或过去回填计划。

空周期显示空状态，不写假事件；3个月只回看有日历定义的周期，早于可追溯起点停止。会话历史不被跨日强跳，当前列跟随日历；重新启动回当前并保留窗口 / 主题。

历史仅纳入**曾明确安排到该尺度 / 周期**的条目并按 ID 去重；日任务不隐式成为月计划。月→周→今天的旧位置只在对应历史页留下引用，不留在当前月 / 周列。同周期往返汇总一行，活动保留真实操作。区分期末与后续结果：

| 场景 | 展示 |
| --- | --- |
| 9月计划，10月顺延并完成 | 9月底未完，另列后来顺延 / 完成；10月有真实计划 |
| 9月遗留10月直接完成，未调期 | 9月底未完、后来完成；完成列表归10月，无虚假10月月计划 |
| 9月完成10月重开 | 9月保持当时完成，后来重开单列 |
| 月→周→今天后完成 | 历史保留去向，当前只有今天卡片，不算多次顺延 |

取消 / 归档 / 删除 / 还原和撤销也不改写过去。当前标题 / 说明 / 关系需标注，不承诺过去全文、颜色、顺序或完整图。早期无事件显示历史不完整，不由当前状态反推或虚构期末快照。

## 5. 往期未完成与顺延

**无论积压多久或顺延多少次，系统都不会自动归档或删除事项。** 归档、删除由用户主动选择；整库重置只按 §6 明确确认后执行。

**有效旧周期 todo 始终在当前对应列显示「往期未完成 · N」，与策略无关。** 完成 / 取消 / 归档 / 删除排除；hold、自动失败、生效前积压及整库恢复暂停仍可发现。它是旧位置投影，安排前不算当前承诺，数量单列。按周期近到远、同期稳定顺序，可折叠但保留 N。

所选往期项可批量安排当前同类周期 / Later，单项可移列 / 完成 / 取消。「暂不处理」只关闭面板，继续计入 N，不新增 snooze 或隐藏时间；不锁屏、不强制回顾 / 填理由。旧项直接完成按真实完成日可查。

「未完成事项处理」默认见 §2。开启自动从当前源周期起生效，不清更早积压；10月15日开启月自动，9月仍手动、10月到11月可自动。关闭不倒退已发生安排，再启用记录新边界。只移动自身策略允许的旧项到真实当前同类周期，不改 due_date / 关系 / 状态，也不级联上下级。

顺延追加到已有待办后，批内来源近到远 / 原顺序，保留当前顺序。同尺度向后调期记顺延，跨尺度 / Later 记移动，同期排序不算延期。成功才提示批次、来源、查看 / 撤销；来源标记为最近一次同尺度顺延的来源，详情可追溯完整路径，失败保留原位。

撤销预览后按 item / placement 版本和目标位置严格复核，跳过后续编辑 / 排序 / 移动 / 状态变化项并报告。恢复可行相对排序而非覆盖整列；原记录保留，追加逆操作，同一效果最多逆转一次，0项不能报成功。

**任意撤销返回已结束周期的 todo，都设置执行时当前同类周期的 hold，不以 auto 策略为条件。** 包括顺延、移位、状态和可见性操作的撤销；当前周期 / Later 不需 hold。hold 持久化，本周期不被自动搬回，仍在往期入口；下一周期可按策略处理，新的手动移位清除旧 hold。

启动 / 唤醒 / 前台 / 日历边界核对，无退出后常驻要求。9月退出、11月打开只记实际9→11一次，不虚构10月；反复触发不重复，浏览历史不触发对历史周期写入。

## 6. 图标、备份与隐私

所有 UI 图标统一 **Hugeicons**，含 shadcn 内部关闭、箭头、勾选、Toast / 加载；默认免费 Stroke Rounded，本地按需打包，不混用其他库或 emoji 占位，无 CDN / 远程SVG / 图标字体。按钮有可访问名称，装饰图标不重复朗读。品牌 Logo / 启动图标另行设计；原生控件、正文 emoji 和关系连线不受图标来源规则限制。

SQLite 位于稳定应用数据目录，核心操作离线与重启可用。完整 JSON 包括任务、关系、日历、周期、设置、历史、批次、undo / hold。**备份 / JSON 恢复**均先校验 / 预览 / 确认 / 保护备份再原子替换，失败保留原库，不做智能合并；成功设置整库自动补处理暂停，用户确认才解除，重启不绕过。暂停时还原 / 解除归档 / 普通编辑仍可用，但不解除暂停。

日常备份默认开启：每个工作区当地日期首次启动 / 唤醒 / 前台检查、或持续打开跨日时，在自动顺延前尝试一致性备份；当天成功后不重复。设置展示位置、最近结果、启用状态、保留数 N（默认7）和恢复入口。成功校验新副本后才轮换超量旧副本，仅清本应用日常备份，不清用户导出或迁移 / 恢复前保护副本。失败保留原库与旧备份、提示重试；日常备份失败不阻断正常编辑，保护备份失败则停止对应危险操作。退出期间无伪造备份，同盘备份不能防止整块磁盘丢失。

**重置工作区：** 设置 → 数据 → 重置工作区。先预览将移除的全部条目（含归档 / 回收站）、关系、周期、活动历史、操作回执及工作区设置；用户选择「创建保护备份并继续」后才备份。备份成功并校验后，显示位置与恢复方式，再要求输入「重置」并点击「重置并重新配置」，才原子替换为空工作区。备份失败、最终取消或替换失败都保留原数据，不允许跳过保护备份。操作期间暂停写入与自动顺延，取消 / 失败恢复原运行状态。

成功后清空旧会话撤销栈 / Toast、历史缓存和当前任务选择，返回首次配置页；任务 / 关系 / 历史及工作区日历和策略重新开始，应用主题 / 语言及既有备份文件保留。空工作区由未完成首次配置阻止写入，不设置「恢复后等待顺延」暂停；再次打开仍进入配置页。重置不进撤销栈，只能通过保护备份恢复旧工作区，不能与重置后新建数据自动合并。保护备份不参与日常轮换；重置不是安全擦除，也不是自动归档 / 删除积压。

可信历史保留身份 / 时序；无历史旧数据按真实导入时刻建立 baseline，未知完成 / 取消时间明确标记。任务、回收站、历史、截图、导出和备份均属私人数据，无正文遥测，不宣传本地 SQLite 为端到端加密；公开分发、采购和 DNS 操作另行授权。
