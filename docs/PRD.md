# Goalloom · 产品需求

v0.5 · 2026-09-22。评审修订，仍由本文件维护产品规则，[TODO](TODO.md)维护工程与验收。新增交互和备份参数为本轮采纳的实施默认；D06 / D07 的候选方案仍需 M0 确认，不冒充已获逐项批准。

## 1. 产品与首版范围

**把长期方向拆成行动，再安排到合适的时间。** 面向个人，不要求学习企业 OKR 流程。

首版为 **Electron 的 macOS / Windows 本地桌面**，采用 React、TypeScript、Vite、shadcn/ui、Tailwind CSS、Hugeicons 和 SQLite。核心是五列、录入编辑、拖拽排序、实体关联、搜索、历史、未完成事项处理和可靠备份恢复。

沿用「不做进度同步」的解释：完成、重开或取消只影响自己，不汇总百分比或联动父子状态。引用更新显示同一实体的新信息，不算状态传播。

**后置：** 进度 / KR、重复任务、提醒、普通分类标签、系统全局快速录入、通用批量管理、未来周期排期、完整复盘 / 内容版本、Markdown 导出、自动更新、托盘和毛玻璃。账号、云同步、Web / 移动端、团队、AI、日历集成和计费另行立项；不自动归档或删除积压。轻量 SVG 连线是核心高亮完成后的可选增强，不阻断首版。

## 2. 看板、时间与条目

### 2.1 时间规则

| 固定列名，从左到右 | 含义 | 周期结束后默认 | 首版可设置 |
| --- | --- | --- | --- |
| Later | 尚未承诺时间 | 不处理 | 无周期、无顺延策略 |
| 3个月 | 自定义目标周期，内部称 cycle | 手动安排 | 固定手动；参数见 D07 |
| 本月 | 当前自然月 | 手动安排 | 可开启自动 |
| 本周 | 当前周 | 手动安排 | 默认周一开始，可更改；可开启自动 |
| 今天 | 当前日 | 自动顺延至新的当天 | 可改手动 |

「周期」泛指上述四种有日期的区间；界面统一用「3个月」，不把它与自然季度混用。初次启动读取系统 IANA 时区作为工作区时区，在设置显示并允许确认；检测失败要求选择，不猜测。之后不自动跟随系统时区变化，只提示用户选择是否调整。日界、日期型截止提示和完成日期展示以工作区时区为基准，历史周期使用其固定边界。

三个月可自定义已确认；**D07 候选方案**是首次默认以工作区今天为锚点，可自选不晚于今天的起点，按固定 3 个日历月推导覆盖今天的一轮。例如 `[2026-09-21, 2026-12-21)`，结束日不含在内；原锚点加 `3n` 月、月底截断，不逐轮漂移或写死 90 天。是否采用这一参数方案在 M0 确认，独立结束日 / 任意时长未批准。月 / 周可跨 cycle 边界，关联不强制日期包含。

**修改日历规则的安全边界：** 工作区时区、周起始日，以及 D07 若开放的锚点重设，均先预览、明确确认，按受影响尺度在旧当前周期的结束边界后生效。原周期 ID、结束时刻和已有条目归属不变，不能因保存设置就把当前任务判成往期；到真实旧边界后，未完成项才按该尺度策略处理。设置显示各列实际生效时间；不同时结束的列暂沿用各自旧规则，并标注其日期 / 时区。工作区显示时区在旧当前日结束后切换，不重写 due_date 文本或旧历史。

新旧边界不对齐时，建议从旧结束边界连续接到新规则下的下一边界，显式标为「过渡周期」并显示真实起止；之后按新规则完整周期运行，不能留空档、重叠或给任务新增第二位置。例如周一改周日：旧周仍到下周一，接一段周一至周日的短过渡周，再按周日开周。边界恰好对齐则直接进入完整新周期。D07 的任意新锚点可能造成不同长度的过渡，开放前必须在 M0 核定允许范围；不能用「下一周期生效」替代这项决定。待生效变更可撤销 / 替换，规则保存本身不制造任务移动或伪造离线操作。

### 2.2 唯一位置与录入

**每个条目只有一个 ID、一份状态、一个主位置。** 本周移到今天后，当前本周列既不显示它的任务卡片，也不保留只读引用卡片。只有搜索、详情和明确的历史模式能展示引用；旧周期往期入口是唯一旧位置的操作投影，不是复制到新周期。不要求任务走完五列。移动保留内容、状态、截止日和关联；拆解创建新 ID 和关系，父项留原位。

统一条目，无首版 `kind` 类型字段 / 选择器，也无自定义颜色字段 / 设色入口。「目标」「任务」只是内容用途的描述，不能把「有下级」当成目标成立的必要条件，尚未拆解的目标也正常存在。

当前模式的每列可添加。应用内 Cmd/Ctrl+N 默认进入当前聚焦的可编辑列，无列焦点则 Later；焦点在历史列时也回落 Later 并提示，不往历史写入。标题去空白后必填，同名不合并；标题 Enter 提交、Esc 取消。说明为多行纯文本，Enter 换行、Cmd/Ctrl+Enter 保存。所有提交快捷键均避开 IME 组合输入；说明未保存时关闭先提示，不静默丢内容。

`due_date` 可选且独立；移动 / 顺延 / 日历规则调整不得自动改变。只有实际截止日已过才显示截止逾期。首版不能直接排到下周 / 下月：周日晚要规划下周，只能先放 Later 或等周一再安排；填写未来截止日不等于未来排期。界面明确显示此限制，不用隐藏日期功能暗中扩大范围。

### 2.3 状态、视图与恢复

标题栏「视图」菜单与命令面板提供「看板、已完成、已取消、归档、回收站」；设置另有入口。这些是辅助视图，不是第六个时间列。搜索覆盖未删除条目的标题 / 说明，包括历史关联、已完成、已取消和归档，结果注明当前位置 / 状态；删除项只在回收站搜索，不混入普通结果。

| 操作 / 状态 | 当前列与列表 | 返回路径 |
| --- | --- | --- |
| 待办 todo | 未归档 / 删除且属当前周期，在对应列；旧周期见往期入口 | 正常编辑 / 安排 |
| 完成 done | 当前位置所在列的「已完成」折叠区，Later 同样适用；旧周期不混入当前列 | 「已完成」或历史详情可重开 |
| 取消 cancelled | 表示不再做，从当前列与往期区移出，不混入已完成折叠区 | 「已取消」可重新打开为 todo |
| 归档 | todo / done / cancelled 均可归档；不改状态、计划或关系，从活跃列与往期区隐藏 | 「归档」解除归档，恢复原状态 / 位置 |
| 删除 | 任意状态软删除；隐藏于上述普通视图，保留原状态 / 位置 / 事件身份，关系失效 | 「回收站」按删除时间查看 / 搜索 / 恢复，Later 项也可恢复 |

全局「已完成」仅列未删除且当前 done 的项，按最新真实 completed_at 分组；「已取消」同理按当前 cancelled 查询。两者可包含归档项并标记归档；历史曾完成但已重开的项不留在当前已完成列表，原完成事件仍保留。归档、状态、删除是独立维度；解除归档不等于重开，回收站恢复也不取消原归档状态。

恢复 / 解除归档 / 重开均不偷偷改计划。旧周期 todo 重新可见后进入往期入口；若符合自动策略，后续 reconcile 可单独产生有提示、可撤销的顺延。恢复关系需重新防环 / 检查基数，非法边跳过并提示，不删除或覆盖其他条目。**P0 不提供彻底删除、清空回收站或定期清除**；未来彻底删除需另外设计历史引用与备份处理，不能级联删除事件身份或声称软删除已擦除内容。

### 2.4 交互与视觉

轻量列表、弱分隔，单列建议 260–340px，独立纵向滚动；窄窗口横向导航可跳到今天，详情用侧边抽屉。提供拖拽与「移动到…」键盘替代，支持空列、边缘滚动、Esc 取消、失败回滚；拖到卡片默认排序，不暗中关联。浅色 / 深色 / 系统主题、焦点、非颜色提示、减少动效和 Cmd/Ctrl+K 搜索均保留。

手动移动（含排序）与完成成功后提供非阻塞提示和撤销，只逆转对应操作，不回放整份任务快照。后续编辑 / 状态 / 排序冲突时跳过并说明；文本框的 Cmd/Ctrl+Z 仍用于文本，不被应用截获。若撤销使 todo 回到已结束周期，也须按 §5 设置本周期 hold，防止自动顺延立即抵消撤销。

## 3. 关联

一种「关联到…」入口，明确选择该条目的**上级**，搜索已有条目并展示列 / 周期 / 状态，保存真实 ID，改名后引用更新。不存在 / 已删除候选不可选，取消不落库；允许跨列跳级和同列，拒绝自关联、重复边与循环。

关系方向为上级→下级，**D06 尚未决定单父树或多父 DAG**。卡片只显示直接上级的「关联标记」，不显示混合上下级的普通标签：单父方案最多一个；若确认多父，最多两个，其余 `+N`。详情分开展示直接上级 / 下级与活动记录；多父路径去重限界，不虚构唯一祖先链。标记颜色由系统根据被引用 ID 稳定派生作辅助，搭配文字，不存用户自定义色。

「拆解下一步」建议从3个月→本月→本周→今天，允许改列；Later / 今天默认同列，创建与关系同事务。解除只删除联系，不删条目或改状态。删除目标先预览影响，仅使其边失效；恢复重新校验，归档不解除关系。

P0 必做关联标记、定位、选中高亮。轻量 SVG 连线安排为 M4 之后可选，不作 M2 或首发门槛；仅连接可见当前条目，滚动 / 缩放 / 抽屉变化重算，屏外提示，历史端点不接当前图。没有连线也能完成全部关联操作。

## 4. 历史：回看不改变现在

除 Later 外，各列独立翻阅过去、返回当前，不联动其他列；历史行只读，不能直接添加 / 勾选 / 拖放。点击打开明确标注的「当前条目」，已删除项转回收站详情。首版不向未来或过去回填计划。

空周期显示空状态，不写假记录；3个月只回看有日历定义来源的周期，早于可追溯起点停止。会话历史页不被跨日强跳，当前列跟随日期；新一次启动回当前并恢复窗口 / 主题。

历史只纳入**曾明确安排到该尺度 / 周期**的条目，按 ID 去重；今天新建不自动成为月计划。月→周→今天的旧位置只在对应历史页留下引用，不出现在当前月 / 周列。同周期往返汇总一行，活动保留各次操作。区分「截至期末状态 / 去向」与「后来结果」：

| 场景 | 展示 |
| --- | --- |
| 9月计划，10月顺延并完成 | 9月底未完成；另列后来的顺延 / 完成，10月有实际计划 |
| 9月遗留，10月直接完成但未调期 | 9月底未完成、后来完成；全局完成归10月，不制造10月月计划 |
| 9月完成，10月重开 | 9月保留当时完成；后来重开单独显示 |
| 月→周→今天后完成 | 历史保留各次去向，当前只有今天卡片，不算多次延期 |

取消 / 归档 / 删除及恢复也不改写历史。使用当前标题 / 说明 / 关系时明确标注，不承诺还原当时全文、配色、顺序或关系图。无早期事件显示历史不完整，不反推过去或捏造期末快照。

## 5. 往期未完成与顺延

**有旧周期有效 todo，当前对应列就显示「往期未完成 · N」，与手动 / 自动策略无关。** 排除完成、取消、归档、删除；hold、自动失败、设置生效前积压和恢复暂停仍可发现。它是旧位置的投影，未安排前不成为当前承诺，数量与当前待办分开。

按原周期近到远、同周期稳定顺序，可折叠但保留数量入口。所选往期项可批量安排到当前同类周期 / Later，单项可移列 / 完成 / 取消。**「暂不处理」仅关闭操作面板，条目仍计入 N、可重新打开，不产生 snooze / 隐藏时间。** 不锁屏、不强制回顾 / 填理由；旧项直接完成按实际日期可查。

「未完成事项处理」默认见 §2。开启自动从当前源周期起生效，不搬旧积压；10月15日开启月自动，9月仍手动，10月到11月可自动。关闭不撤回已发生操作，再开启采用新边界。自动只对唯一主位置策略允许的有效旧项移到真实当前同类周期，不改 due_date / 关系 / 状态，也不沿上下级传播。

新项追加在已有待办之后，批内按来源近到远 / 原顺序，不重排已有计划。同尺度向后调期才记顺延，跨尺度 / Later 记移动，同期排序不算延期。成功提示批次摘要 / 查看 / 撤销，行上标最近一次同尺度顺延来源，详情保留路径；失败保留原位置，不提前报成功。

撤销先预览，再按当前 item / placement 版本和目标位置严格复核；后续编辑 / 排序 / 移动 / 完成项跳过并报告。恢复可行相对位置，不覆盖整列；保留原事件、追加反向记录，同一操作效果至多撤销一次，0项不能宣称成功。

凡撤销使 todo 回到已结束周期（包括自动顺延、手动跨期移动或旧项完成的撤销），都落盘 **执行时当前同类周期的 hold**，本周期不再次自动搬回，仍显示往期入口。普通当前周期操作的撤销不需 hold。下周期可重新按策略处理，用户手动移位清除旧 hold；不永久冻结任务。

启动 / 唤醒 / 前台 / 日历边界核对，不要求退出后常驻。9月关闭、11月重开只记录实际9→11一次，不虚构10月。浏览历史不触发对历史周期的写入；预先保存的日历规则可推导区间，不等于曾后台移动任务。

## 6. 图标、备份与隐私

所有应用 UI 图标使用 **Hugeicons**，含 shadcn 内部关闭、箭头、勾选、Toast 和加载图标，不混用其他库或 emoji 占位。默认免费 Stroke Rounded，不推断已购 Pro；本地按需打包，无 CDN / 远程 SVG / 图标字体请求。图标按钮有可访问名称；装饰图标不重复朗读。品牌 Logo / 启动图标另行设计；原生控件、正文 emoji 和关系连线不受功能图标规则限制。

离线核心与重启恢复必须可用，SQLite 存稳定应用数据目录。完整 JSON 包含任务、关系、周期与日历规则、设置、历史、批次和 undo / hold。覆盖恢复先校验 / 预览 / 确认 / 备份再原子执行，失败保留原库，不做智能合并；恢复后暂停自动补处理，用户确认才继续，重启不能绕过。

**日常备份实施默认：** 每个工作区当地日期首次启动 / 唤醒 / 前台检查时，在自动顺延前创建一致性备份；持续打开跨日也检查，退出期间不伪造备份。设置展示启用状态（默认开）、位置、最近成功 / 失败、保留数 N（默认7）与恢复入口。仅轮换本应用的日常自动备份，成功校验新副本后才删除超量最旧副本；不自动清理用户导出或恢复前 / 迁移前保护副本。失败保留原库与旧备份、提示重试，不因此阻断正常安全编辑；强制恢复 / 迁移前备份失败则停止该危险操作。备份不能替代导入校验，也不能防止同一磁盘损坏。

可信历史保留身份 / 时序，无历史旧数据从实际导入时建 baseline。任务、历史、截图、回收站和备份均属私人数据；无正文遥测，不宣传 SQLite 为端到端加密。公开分发、付费采购和 DNS 操作另行授权。
