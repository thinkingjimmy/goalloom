## 1. 产品与首版范围

**把长期方向拆成行动，再安排到合适的时间。** 面向个人，不要求学习企业 OKR 流程。

首版为 **Electron 的 macOS / Windows 本地桌面**，使用 React、TypeScript、Vite、shadcn/ui、Tailwind CSS、Hugeicons 和 SQLite。核心是五列、录入编辑、拖拽排序、目标关联、搜索、历史、未完成事项处理和可靠导出恢复。

沿用「不做进度同步」的解释：完成、重开或取消只影响该条目，不汇总百分比、不联动父子状态。引用刷新显示同一实体的新标题 / 状态，不算传播。

**后置：** 进度 / KR、重复任务、提醒、普通标签、全局录入、通用批量管理、未来周期排期、完整复盘 / 内容版本、Markdown 导出、自动更新、托盘和毛玻璃。账号、云同步、Web / 移动端、团队、AI、日历集成和计费另行立项；不自动归档或删除积压。

## 2. 看板与条目

| 从左到右 | 含义 | 周期结束后默认 | 首版可设置 |
| --- | --- | --- | --- |
| Later | 尚未承诺时间 | 不处理 | 无周期，无顺延设置 |
| 3个月 | 自定义目标周期 | 手动安排 | 固定手动 |
| 本月 | 当前自然月 | 手动安排 | 可开启自动 |
| 本周 | 当前自然周，建议周一开始 | 手动安排 | 可开启自动 |
| 今天 | 工作区当地日 | 自动顺延至新的当天 | 可改手动 |

三个月可自定义已确认；实施草案为自选起点加 **3 个日历月**，不是滚动 90 天。例如 `[2026-09-21, 2026-12-21)`。月底截断到有效日期，后续边界从原始锚点计算，避免逐轮漂移；参数边界见 §7。月 / 周可跨目标周期，关联不强制日期包含。

**一个条目只有一个 ID、一份状态、一个主位置。** 本周移到今天后不再作为本周主卡片出现；搜索、目标详情和历史只是引用。移动保留内容、状态、截止日和关联；「拆解下一步」创建新 ID 和关系，父项留原位。不要求任务走完五列。

每列可添加，全局新建默认 Later；标题去空白后必填，同名不合并。Enter 提交、Esc 取消，中文输入法选词时不提交。说明先用文本。目标 / 任务共用模型，不增加 O / KR / Initiative 体系。

状态为待办、完成、取消，支持重开。当前周期完成项进入本列折叠区；归档、取消、删除不混用。删除进回收站，不级联删其他条目。全局已完成列表仅列当前 done 项，按最新真实 `completed_at` 分组；重开不删除旧完成事件。

`due_date` 可选且独立；移动 / 顺延不得修改。原计划昨天不等于逾期，只有实际截止日期已过才显示截止逾期。

**界面：** 轻量列表与弱分隔；单列建议 260–340px、独立纵向滚动，窄窗口横向导航并能跳到今天；详情用侧边抽屉。提供拖拽及「移动到…」键盘替代，支持空列、边缘滚动、Esc 取消和失败回滚。拖到卡片默认排序，不暗中关联。搜索覆盖标题 / 说明、历史与归档，至少可靠支持中文子串。支持浅色 / 深色 / 系统主题、焦点、非颜色提示、减少动效；快捷键建议 Cmd/Ctrl+N、Cmd/Ctrl+K、Esc，不抢文本编辑快捷键。

参考：[多列看板](references/01-time-board.png) · [目标关联](references/02-goal-links.png)。只借鉴布局与交互，不复制原品牌、真实任务或平台假按钮。

## 3. 关联

使用一种「关联到…」入口，搜索已有目标 / 任务并展示列、周期和状态；保存真实实体 ID，改名后引用更新。选择取消不落库，不存在 / 已删除目标不可关联。允许跨列跳级及同列关联；自关联、重复边和循环必须拒绝。

关系方向为上级 → 下级；**一个下级能否有多个上级仍待确认**，不能由主位置唯一推导。标签最多显示两个，其余 `+N`；颜色辅助文字，不强制改写条目自定义色。详情展示上级 / 下级和活动记录；多父方案下不得虚构唯一祖先路径，遍历须去重限界。

「拆解下一步」默认建议三个月→本月→本周→今天，允许改列。解除关系不删任务或改状态。删除目标先说明影响，只使关系失效；恢复时重新校验，跳过非法关系并提示，不覆盖新关系。归档保留关系并标注归档状态。

默认不展示全部连线。先做标签、定位、选中高亮，再做轻量 SVG；只连接可见的当前条目，滚动 / 缩放 / 抽屉变化后重算，屏外给提示。历史行不接入当前关系图。

## 4. 历史：回看不改变现在

除 Later 外，各列独立翻阅过去、返回当前，不联动其他列。历史行只读，不直接添加、勾选、拖动或接收落点；点击打开明确标注的「当前任务」，已删除项只提供相应恢复入口。首版不向未来或过去回填计划。

空周期显示空状态，不写假记录；三个月只回看已定义周期，早于可追溯起点停止。会话中历史页不被跨日强行跳走，当前列跟随日期；新一次启动回当前，恢复窗口和主题。

历史只纳入**曾明确安排到该尺度 / 周期**的条目，按 ID 去重。今天创建的任务不自动成为月计划；月→周→今天可留下引用，但当前只有一个位置。同周期移出再移回显示一条汇总，活动记录保留各次操作。

区分「截至期末的状态 / 去向」和「后来的结果」：

| 情况 | 正确展示 |
| --- | --- |
| 9月计划，10月顺延并完成 | 9月底未完成；后来顺延 / 完成。10月有实际计划与完成日期 |
| 9月遗留，10月直接完成但未调期 | 9月底未完成、后来完成；全局完成列表归10月，不制造10月月计划 |
| 9月完成，10月重开 | 9月保留当时完成，另示后来重开 |
| 月→周→今天后完成 | 保留各次计划去向，不计为多次延期，不复制 Todo |

取消、归档、删除及恢复同样不能用当前状态覆盖历史。标题 / 说明 / 关联读取当前信息时明确标注，不承诺还原当时全文、配色、顺序或关系图。无早期事件则显示历史不完整，不反推过去；不要求完整期末快照。

## 5. 往期未完成与顺延

**只要存在旧周期的有效待办，当前对应列就显示「往期未完成 · N」，不论策略是手动还是自动。** 排除完成、取消、归档和删除项；撤销抑制、自动失败、设置生效前积压、恢复暂停的事项仍须可见。它是旧位置的投影，未处理前不成为当前承诺，数量与当前待办分开。

按原周期近到远、同周期稳定顺序展示，可折叠但保留数量入口。支持所选往期项批量安排到当前同类周期 / Later；单项还可移列、完成、取消或暂不处理。不锁屏、不强制回顾或填理由；旧项直接完成按实际日期可查。

设置名为「未完成事项处理」，默认值见 §2。开启自动从当前源周期起生效，不搬旧积压；例如10月15日开启月自动，9月遗留仍手动，10月事项到11月可自动。关闭不撤回已发生操作，再开启采用新生效边界。

自动只处理自身主位置策略允许的有效旧待办，移到真实当前同类周期；不动截止日、关联、状态或上下级。追加到目标列已有待办之后，批内按来源近到远 / 原顺序，不重排现有计划。同尺度向后调期才是顺延，跨尺度 / Later 是移动，同期排序不是延期。

成功后显示批次摘要、查看、撤销；来源标记为最近一次同尺度顺延的来源，详情可追溯完整路径。失败保留原位置，不提前显示成功。撤销预览冲突，执行时只恢复版本及目标位置仍匹配的项；后续编辑 / 排序 / 移动 / 完成等已修改项跳过并报告。原事件保留，追加反向事件，恢复可行的相对排序，不覆盖整列新安排。

撤销在**执行时的当前同类周期**落盘抑制，不因重启立刻顺延回去；下一周期可按策略处理，手动移位清除旧抑制。同事件最多撤销一次，0项可撤销不能宣称成功。

启动、唤醒、前台恢复和日历边界检查，无需退出后常驻。9月关闭、11月重开只记录实际9→11的一次操作，不虚构10月；浏览历史不触发针对该历史周期的写入。

## 6. 图标、数据与隐私

所有应用 UI 图标使用 **Hugeicons**，包括 shadcn 内部关闭、箭头、勾选、Toast 和加载图标；不混用 Lucide 等库或 emoji 占位。默认免费 Stroke Rounded，不推断已购 Pro。图标本地随包、按需导入；按钮有可访问名称，装饰图标不重复朗读。品牌 Logo / 启动图标另行设计，原生系统控件、任务正文 emoji 与关系连线不受功能图标规则限制。

离线核心功能与重启恢复必须可用，SQLite 存稳定应用数据目录。JSON 完整导出任务、关系、周期、设置、历史、批次与撤销抑制；覆盖恢复必须校验、预览、确认、备份并原子执行，失败保留原库，不做智能合并。恢复后暂停自动补处理，用户确认才继续，重启不能绕过。

迁移前一致性备份；可信历史保留身份 / 时序，无历史旧数据从实际导入时建立基线，不伪造旧事件。任务、历史、截图和备份均私人；无正文遥测，不把本地 SQLite 宣传为端到端加密。公开分发、付费采购和 DNS 操作另行授权。
