# 按上级自动排序

> 设置 → 工作区 → 看板：按最近一级上级排列本月、本周、今天及未来周期；关闭后保留排列。

## 产品规则

- 单一本机开关，默认关闭，不进入备份或导出。「完成撒花」迁入同页，保持原有五列选择、预览与本机偏好。
- 最近一级有效上级优先；同尺度多个上级取排最前者，仅作为排序依据，不改变多父关系。不同尺度先近后远，同尺度跨周期按起点；最后按手动排序键与 ID 稳定排列。无有效上级的条目排最后。
- 同组可以鼠标／键盘手排，跨组拖动限制在组边界；跨列后按目标列的有效上级归位。完成与未完成各自展示。滚出视口、筛选、完成和归档不改变上级依据。
- 看板圆点和详情中的关联选择器同步使用看板候选顺序，保留已绑定置顶与最近一级优先；搜索命中的当前／已加载未来候选同样跟随。
- Later、3个月和历史不自动排序；历史上级使用保存顺序。失效边及移动后不再满足上长下短的边不参与。
- 开启仅派生显示顺序；关闭先原子保存所有当前／未来周期的排列，再关闭开关。作为排序依据的归档／取消条目也保存顺序，保留状态，防止中间祖先的相对位置改变下级分组。失败保持开启，未知结果先查原回执。保存排列可一次撤销，但不会重新开启开关。
- 重排保持行身份、焦点、草稿与滚动位置，约 240 ms 位移，关系线与断点同步跟随。首次加载／换期不播放，减少动态效果时直接定位。

## 工程契约

- 纯排序函数共用于 renderer 与权威事务，时钟由调用方注入。摘要仅补充相关祖先的 ID、位置、周期与排序键，无正文。
- `move.parentOrder` 在事务中复核有效分组；`materializeParentOrder` 以单事务、幂等回执及顺序位置效果保存排列，不改变状态、关系、周期或 hold。当前与未来读模型刷新后完成本机切换。
- 外层 FLIP／WAAPI 与内层 dnd-kit 分工；仅暂留前后可见窗口，动效可打断且无闲置逐帧任务。工作区代次变化清理缓存与待完成动作。

## 实现前失败场景

- 多级排序不连动、多父随机选择、跨级／跨期顺序不稳定，隐藏或归档上级丢失。
- 组内拖动改变组外顺序，跨列丢失关联，错误邻居／旧版本／旧代次绕过事务复核。
- 关闭后弹回旧序，只保存当前屏幕，忽略隐藏祖先导致分组二次变化，批量保存部分成功、重复写入或撤销破坏正文与 hold。
- 当前快照混入旧未来元数据，失败／未知回执错误关闭开关，恢复后旧请求污染新工作区。
- 行重挂载、动画打断闪跳、拖放回弹、连线漂移、虚拟列表无限挂载，焦点／草稿／滚动丢失。
- 看板已经自动排序，关联上级选择器却仍按旧序列出候选，或搜索后丢失看板顺序。
- 开关重启丢失、进入备份，撒花入口失效、缺少翻译，减少动态效果仍播放。
