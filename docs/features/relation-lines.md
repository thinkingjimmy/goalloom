# 关系线

> 筛选单个流程时，用线把它的上下级连起来；开关只在「设置 → 外观 → 关系线」，本机偏好，默认开。

## 产品规则

- 只在顶栏选中某一个流程时画线；「全部」不画。筛选语义不变：其他流程的条目留在原位、原顺序，只置灰（内容 28%），不隐藏。
- 线只连当前流程内的上下级（两端都属于该流程）。跨流程的上级不画，只在详情里看到。线只读，不改数据、不进撤销栈。
- 样式：流程色、1.5px、60% 不透明，两端 6px 圆点；上级右端出、下级左端入，同列上下级从右侧绕出。画线时每行右侧让出走廊（行右外边距 24px），行底色不透明，线从行后穿过、不压文字。
- 跨过中间列（按固定列序判断，包括中间列被隐藏）用虚线，并沿中间列的行间边界横穿，不会看起来像从经过的行里出发。
- 多个上级各一条线，等重汇到同一入口圆点。
- 悬停或键盘聚焦本流程的某项：它的全部祖先与后代链 100%、2px，其余线 12%、其余本流程行置灰；离开 120ms 后恢复，避免扫过时闪烁。
- 端点滚出本列视野：线停在列顶/列底，挂「↑/↓ N」标记（读屏：「上方还有 N 项相关」）；点击滚动到最近的那一项。未挂载的行（折叠的已完成、虚拟窗口外、历史模式列）不画线。已完成项展开时线降到 30%。
- 切换流程时线按列依次画出（每条 500ms，列间 70ms）；减少动态效果时直接显示。拖动时线隐藏，放下后按新位置重画。
- 顶栏不放任何关系线入口。

## 工程契约

- `src/renderer/state/relation-lines.ts`：`useRelationLines` 外部存储，localStorage `goalloom.relationLines`，只在关闭时存 `'false'`；不进入工作区数据、历史、导出或备份。
- `src/renderer/features/board/RelationLines.tsx`：由 `Board` 在「筛选中 + 开关开」时挂载于 `.board` 内、各列之前（`key` 为流程 id 以重放画线）。从快照 `relations` 与 `flows.of` 求本流程的边；几何读取已挂载行的 DOM 位置，经 MutationObserver（忽略自身）、ResizeObserver、捕获阶段 scroll 与 transitionend 以 rAF 合并重算。链高亮通过行上的 `data-chain-out` 属性，卸载时清除。
- 样式在 `styles.css` 的 Relation lines 段；`data-dimmed` / `data-chain-out` 只淡化行内容（不含拖动柄），保证行底色遮住线。
