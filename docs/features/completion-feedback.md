# 完成反馈与撒花

> 眼前可见的高频操作安静保存，条目去向、批量变化和撤销结果按需反馈；完成重要周期的事项时，从窗口左右下角撒花。设置入口：「设置 → 外观 → 完成撒花」。

## 产品规则

### 底部 Toast

是否显示成功 Toast 与是否支持撤销分开判断；不改变现有会话撤销成员，快捷键与命令面板撤销继续可用。

| 操作 | 成功反馈 |
| --- | --- |
| 列头新建、拆解下一步 | 静默 |
| 拖拽、键盘移动、详情移动、往期批量安排、完成 | 静默 |
| 添加、解除上下级关联 | 静默 |
| 全局新建单条、重开、解除归档 | 条目在底层看板当前可见时静默；否则显示结果及去向 |
| 全局批量新建 | 显示数量与整批撤销入口 |
| 取消、归档、删除 | 显示结果与撤销入口 |
| 还原条目 | 显示结果、去向与撤销入口 |
| 系统自动顺延、撤销顺延批次 | 保留批次反馈，明确数量及跳过情况 |
| 每次成功撤销 | 显示原操作；撤销单条新建保留「还原」，撤销批量新建保留「查看回收站」 |

- 「当前可见」以底层看板的实际行位置判断：隐藏列、列处于历史视图、折叠或滚动到视野外的行都不算可见；详情、设置等弹窗遮挡不影响判断。流程筛选只淡化其他行，不将其视为隐藏。
- 去向文案包含所在列；按实际结果补充「往期」「已归档」及非 TODO 状态。隐藏列与当前视图未显示时补充原因，避免只说「已还原」而无法找到条目。
- 不带还原入口的普通撤销提示显示约 2.5 秒；带操作入口或批次信息的提示显示约 6 秒。悬停、键盘聚焦及保存忙碌期间暂停关闭。新提示替换当前提示，不排队堆积。
- 还原成功但部分内容未恢复时，合并为一条持续显示的警告 Toast，包含去向与未恢复原因，提供关闭和撤销；不同时叠加顶部警告与普通成功 Toast。完全失败、撤销冲突等继续使用现有错误反馈。
- 文字编辑、流程颜色与设置继续静默；文字编辑和流程颜色不因此新增全局撤销能力。刷新、重复回执和未改变状态的请求不新增成功提示。

### 完成撒花

- 默认「3个月、本月、本周」开启撒花，「Later、今天」关闭；五列均可独立切换，包括隐藏列。按完成时所在列判断，无关所属流程或上级所在列。
- 设置是外观卡片中的一行：标题与说明右侧为「试一下」，下方为与看板同序（Later → 今天）的五个多选列按钮；全部取消即关闭，说明随之提示。「试一下」立即播放一轮预览，不受列开关影响、不写入任何数据；系统减少动态效果时不可用。
- 看板和详情内主动完成均适用，包括详情中不在当前看板的往期／归档事项。完成提交确认成功且确实改变状态后，只播放一次。刷新、重复回执、无变化的请求、失败、撤销和数据恢复不播放；撤销完成后再次主动完成可再次播放。
- 左右下角同时向上、向内喷出彩纸，每侧约 90 片，约 2.5 秒散尽；无声音，不阻止输入、点击、拖拽或快捷键，不移动焦点。详情打开时撒花仍在其上方。起点严格贴合窗口下角，不内缩或藏在下沿外；第一帧立即绘制角落粒子，随后以更宽的扇面覆盖两侧、中央及窗口上部，按窗口尺寸缩放。
- 连续完成重新开始一轮，不累积无限粒子。窗口隐藏、工作区更换、组件卸载或系统开启「减少动态效果」时立即结束，不在恢复可见或关闭减少动态效果后重播。
- 设置即时生效，在本机重启后保留；不进入工作区历史、导出或备份。系统减少动态效果优先于各列偏好，设置显示原因但保留用户选择。文案覆盖中、英、日、西、法。

## 工程契约

- renderer 集中按命令、权威结果及底层看板可见性选择反馈；`create`、`move`、`arrangeBacklog`、完成状态、`link`、`unlink` 静默，单条 `createPlan`、重开与解除归档按结果位置判断。多条 `createPlan`、取消、归档、删除、还原及系统批次保留反馈；撤销反馈优先于原操作的静默规则。
- 位置与状态从已提交结果对应的快照或详情读取；只判断底层行与列滚动区域，不将弹窗遮挡或流程筛选淡化误判为不可见。反馈查询失败不将已提交操作报为失败，不影响保存或撤销。
- Toast 时长由反馈类型决定：普通撤销且无 `restoreSource` 为 2.5 秒，其他普通反馈为 6 秒，还原部分成功警告不自动关闭；暂停与工作区代次清理沿用现有反馈生命周期。文案覆盖中、英、日、西、法。
- `FeedbackLayer` 将提示挂到当前原生模态框内的非模态 top layer；弹窗关闭后回到页面。提示不抢焦点，空白区域点击穿透，在详情／回收站内可直接关闭或撤销。
- `state/use-workspace.ts` 在权威刷新与 `UndoSession.accept` 去重后生成 renderer 内部 `CompletionEvent { operationId, generation, horizon }`；保留原命令上下文处理未知结果的回执恢复。优先从刷新快照读取列，缺失时查询详情；查询失败只跳过动效，不将已提交操作报为失败。代次变化清除旧事件。
- `state/celebration.ts` 提供逐列外部存储、设置页预览信号与系统减少动态效果订阅；预览复用同一画布与生命周期。localStorage `goalloom.celebration` 只保存与默认不同的已知布尔字段；非法字段各自回退默认，存储不可用时仍保留本次会话设置。
- `CompletionCelebration` 只消费新事件身份。Canvas 2D 与单个 requestAnimationFrame 驱动有限粒子，DPR 上限 2，无闲置绘制、无逐帧 React 更新。非模态 manual popover 位于 top layer；画布与 backdrop 均透明且不拦截指针，装饰内容不进入可访问树。
- 粒子出生位置为 CSS 像素坐标 `(0, innerHeight)` 和 `(innerWidth, innerHeight)`；摆动在出生时为零。分层采样水平速度，让每轮同时包含近乎竖直和横跨中央的粒子；拉开垂直速度范围，避免收束成两条窄轨迹。
- 不增加动画依赖，不更改数据库、IPC、CSP、备份格式或撤销成员。渲染失败不影响保存或撤销。设置变化不重播旧事件。
