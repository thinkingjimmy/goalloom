# 完成反馈与撒花

> 眼前可见的高频操作安静保存，条目去向、批量变化和撤销结果按需反馈；完成重要周期的事项时，从窗口左右下角撒花。设置入口：「设置 → 工作区 → 看板 → 完成撒花」。

## 产品规则

### 已完成任务显示

- 「设置 → 工作区 → 看板 → 折叠已完成任务」默认关闭，新用户与没有此项偏好的已有用户一致。关闭时，完成与重新打开只更新状态，保留当前持久化排序位置，继续显示勾选与删除线；不出现独立的已完成分组。
- 开启后，沿用列底部可展开的已完成分组。二级任务保持整组结构，只有全部可见成员完成后才进入该分组。
- 全局应用于 Later 和六个时间列的当前／未来周期；往期列表和设置中的已完成管理页保持现状。
- `collapseCompleted` 为同步的布尔显示偏好，默认 `false`，本机键为 `goalloom.collapse-completed`。缺失／无效值回退默认；切换不改变任务、排序键、历史或会话撤销。复用已有设置 IPC 和 `pref.set`，不增加数据库版本。
- 混排的行、虚拟导航、拖拽和顶栏流程／数字快捷键共用显示顺序。保留周期、所属任务等事务校验；按上级自动放置仍遵循[当前自由排序规则](board-ordering.md)，不恢复已取消的父级分组限制。添加任务、未完成计数与洞察继续读取真实 todo。
- 远端偏好在行内编辑或拖拽结束后应用，避免卸载草稿或拖拽源；只应用最新远端值，不回传设置。
- 验收覆盖原位完成／重开／撤销、折叠、重启、远端应用／无回传、七列／未来／二级任务、混排拖拽／快捷键、虚拟列表、五语言和四外观。失败风险包括完成后跳位、分组拆散、切换写入任务、默认值误同步、顺序与快捷键不一致。命令 `pnpm test:completed-layout`，证据位于 `output/tests/completed-layout/`。

### 底部居中工作区通知

- 错误、时钟异常、时区差异、恢复确认、备份失败与同步待核对使用底部居中通知，与撤销 Toast 使用相同锚点、底色、阴影和轻量操作按钮。宽度随内容增长，最大 620px，正文完整换行，不自动消失，不占用看板高度。操作优先同行靠右，窄窗口下移到正文下一行并靠右；无额外操作图标，空闲／悬停／核对禁用态在明暗主题中均保持可读。
- 保存结果未知时持续显示原操作的「重试核对」，核对期间禁用按钮并显示进度；不提供关闭按钮。只核对原请求，不创建替代写入。普通错误可关闭；时区／备份沿用条件 token 的关闭记忆；时钟／恢复／同步保留原确认入口。同步核对弹窗打开时隐藏其重复入口，关闭后按剩余数量恢复。
- 2026-10-27 负责人确认：通知与当前成功 Toast 使用 Sonner 原生堆叠、悬停展开／移开收起和自动关闭。保留现有胶囊样式；前台按内容定宽，后层轮廓贴合前台宽度，展开后每条各自按内容定宽。持续提醒保留到关闭或条件解除；成功提示沿用下方时长规则。后层收起时不可点击或进入 Tab 顺序。展开后超出可用高度可滚动；原生弹窗内仍可操作且不抢焦点。整库代次变化移除旧通知与操作，单条新成功反馈仍替换当前成功反馈。
- 实现前失败场景：待核对状态被清空的错误文案隐藏；把 pending 当作执行中导致无法重试；连点产生重复写入；核对失败后没有可关闭的错误；原生模态框阻止通知操作；多条／长文案被截断；关闭状态在普通刷新后失效；通知遮住 Toast 或看板新建；靠右主按钮错位、禁用态不清晰；主题与五语言遗漏。
- Toast 样式统一的实现前失败场景：通知偏离撤销 Toast 的底部居中锚点；短通知被强制拉满宽度；长正文被按钮挤成窄列或省略；窄窗口按钮未换行或与关闭按钮重叠；共用样式在极简外观下失配；新布局改变撤销计时、核对禁用或原生弹窗内的焦点与操作；多条长通知超过可用高度后无法滚动。
- Native-stack failure cases: initial notices publish before the Toaster subscribes; dismissed/resolved notices reappear after a modal transfer; removed-generation actions survive; short messages stretch to a long notice's width; collapsed controls remain focusable; hover/focus/busy holds expire early; pending receipts gain swipe dismissal; expanded long notices overflow a short window; modal clearance observes the declaration placeholders instead of visible notifications.

### 底部 Toast

是否显示成功 Toast 与是否支持撤销分开判断；不改变现有会话撤销成员，快捷键与命令面板撤销继续可用。

| 操作 | 成功反馈 |
| --- | --- |
| 列头新建、拆解下一步 | 静默 |
| 拖拽、键盘移动、详情移动、往期批量安排、完成 | 静默 |
| 右键移到下一周期 | 显示实际目标日期／周期及撤销，保留当前视图 |
| 添加、解除上下级关联 | 静默 |
| 设为二级 todo（拖拽、菜单、回执恢复）、拖至同列一级位置 | 静默；保留快捷键／命令面板撤销与撤销结果提示 |
| 全局新建单条、重开、解除归档 | 条目在底层看板当前可见时静默；否则显示结果及去向 |
| 全局批量新建 | 显示数量与整批撤销入口 |
| 推进说明采用、手写修改、清除及复合排期 | 确认回执后显示实际变化及统一撤销入口；无变化/未知回执不报成功，不播放撒花。见 [智能辅助规格](Goalloom-Smart-Assistance-PRD-TODO-v1.1.md)。 |
| 取消、归档、删除 | 显示结果与撤销入口 |
| 还原条目 | 显示结果、去向与撤销入口 |
| 系统自动顺延、撤销顺延批次 | 保留批次反馈，明确数量及跳过情况 |
| 每次成功撤销 | 显示原操作；撤销单条新建保留「还原」，撤销批量新建保留「查看回收站」 |

- 「当前可见」以底层看板的实际行位置判断：收起的 Later、所选周期与任务实际位置不符、折叠或滚动到视野外的行都不算可见；往期页中的真实任务也参与判断。详情、设置等弹窗遮挡不影响判断。流程筛选只淡化其他行，不将其视为隐藏。往期查询在列内部完成后需重新判断待定反馈，不能因父组件没有更新而漏掉还原提示。
- 去向文案包含所在列；按实际周期补充「未来」或「往期」及日期，另补充「已归档」及非 TODO 状态。Later 收起或当前视图未显示时补充原因，避免只说「已还原」而无法找到条目。已选未来周期中的行也参与可见性判断。
- 不带还原入口的普通撤销提示显示约 2.5 秒；带操作入口或批次信息的提示显示约 6 秒。悬停、键盘聚焦及保存忙碌期间暂停关闭。新提示替换当前提示，不排队堆积。
- 还原成功但部分内容未恢复时，合并为一条持续显示的警告 Toast，包含去向与未恢复原因，提供关闭和撤销；不同时叠加工作区错误与普通成功 Toast。完全失败、撤销冲突等继续使用现有错误反馈。
- 文字编辑、流程颜色与设置继续静默；文字编辑和流程颜色不因此新增全局撤销能力。刷新、重复回执和未改变状态的请求不新增成功提示。

### 完成撒花

- 2026-10-05 负责人确认：周／月／合并复盘完成后，先关闭面板再播放同一轮 confetti；明确不排入也算本次复盘完成。仅确认成功后触发，失败／未知回执不播放；遵循入口所属列开关（合并复盘使用本月）及减少动态效果。完成入口和会话已清理，重载不重播。

- 默认「3个月、本月、本周」开启撒花，「Later、今天」关闭；五列的撒花均可独立切换，包括收起的 Later。按完成时所在列判断，无关所属流程或上级所在列。
- 设置是看板卡片中的一行：标题与说明右侧为「试一下」，下方为与看板同序（Later → 今天）的五个多选列按钮；全部取消即关闭，说明随之提示。「试一下」立即播放一轮预览，不受列开关影响、不写入任何数据；系统减少动态效果时不可用。
- 看板和详情内主动完成均适用，包括详情中不在当前看板的往期／归档事项。完成提交确认成功且确实改变状态后，只播放一次。刷新、重复回执、无变化的请求、失败、撤销和数据恢复不播放；撤销完成后再次主动完成可再次播放。
- 左右下角同时向上、向内喷出彩纸，每侧约 90 片，约 2.5 秒散尽；无声音，不阻止输入、点击、拖拽或快捷键，不移动焦点。详情打开时撒花仍在其上方。起点严格贴合窗口下角，不内缩或藏在下沿外；第一帧立即绘制角落粒子，头几帧在角上形成密集一团，并持续喷出约半秒，让起点在余光里也能落在角上；慢粒子在角旁散落，快粒子以更宽的扇面覆盖两侧、中央及窗口上部，按窗口尺寸缩放。
- 每轮从默认彩纸和 🎉、❤️、✨、🎊、⭐️、🌈、🔥、🥳 九种效果中等概率随机选择，各占 1/9，允许相邻重复。只在开始一轮时选择一次；左右两侧始终使用同一种效果。emoji 轮只喷出多个相同 emoji，不混入彩纸或其他 emoji。任务完成、复盘完成与设置预览共用规则，无新增设置或持久化随机结果。
- 桌面彩纸保留每侧 90 片和 2.5 秒生命周期；emoji 每侧 48 枚、20–28px，保持系统原色、等比尺寸和轻微旋转，不采用彩纸的横向压扁。移动端保留原有入口与轨迹，每侧 14 片、1.6 秒，emoji 字号 18–24pt；逐列开关继续生效，系统开启减少动态效果时停止播放。系统字形可随平台不同。
- 连续完成重新开始一轮，不累积无限粒子。窗口隐藏、工作区更换、组件卸载或系统开启「减少动态效果」时立即结束，不在恢复可见或关闭减少动态效果后重播。
- 设置即时生效，在本机重启后保留；不进入工作区历史、导出或备份。系统减少动态效果优先于各列偏好，设置显示原因但保留用户选择。文案覆盖中、英、日、西、法。

## 工程契约

- renderer 集中按命令、权威结果及底层看板可见性选择反馈；`create`、普通 `move`、`arrangeBacklog`、完成状态、`link`、`unlink`、`nest` 静默，`move.period.kind=next` 显示实际目标及撤销。单条 `createPlan`、重开与解除归档按结果位置判断。多条 `createPlan`、取消、归档、删除、还原及系统批次保留反馈；撤销反馈优先于原操作的静默规则。
- 未来周期提交后先刷新对应 `getBoardPeriods` 摘要，再按布局判定可见性；响应由选择、代次和修订隔离。具体周期交互见[周期规划](period-planning.md)。
- 位置与状态从已提交结果对应的快照或详情读取；只判断底层行与列滚动区域，不将弹窗遮挡或流程筛选淡化误判为不可见。反馈查询失败不将已提交操作报为失败，不影响保存或撤销。
- Toast 时长由反馈类型决定：普通撤销且无 `restoreSource` 为 2.5 秒，其他普通反馈为 6 秒，还原部分成功警告不自动关闭；暂停与工作区代次清理沿用现有反馈生命周期。文案覆盖中、英、日、西、法。
- `FeedbackLayer` 将提示挂到当前原生模态框内的非模态 top layer；弹窗关闭后回到页面。提示不抢焦点，空白区域点击穿透，在详情／回收站内可直接关闭或撤销。 原生模态框按实际通知高度保留空间。
- `FeedbackStack` 只将现有内容和时长交给 Sonner；展开、堆叠变换和退出由原生运行时管理。`sonner/dist/styles.css` 进入本地 CSS 产物，构建时移除同一依赖重复的运行时样式注入，不放宽 CSP。宽度／滚动测量不改变任务数据、回执或撤销成员；原生退出期间的内容立即禁用。开发反馈可选 `workspace-notices.mjs --stack`，完成时运行整个通知脚本。
- `state/use-workspace.ts` 在权威刷新与 `UndoSession.accept` 去重后生成 renderer 内部 `CompletionEvent { operationId, generation, horizon }`；保留原命令上下文处理未知结果的回执恢复。优先从刷新快照读取列，缺失时查询详情；查询失败只跳过动效，不将已提交操作报为失败。代次变化清除旧事件。
- `state/celebration.ts` 提供逐列外部存储、设置页预览、绑定工作区代次的复盘完成信号与系统减少动态效果订阅；预览复用同一画布与生命周期。localStorage `goalloom.celebration` 只保存与默认不同的已知布尔字段；非法字段各自回退默认，存储不可用时仍保留本次会话设置。
- `CompletionCelebration` 只消费新事件身份。Canvas 2D 与单个 requestAnimationFrame 驱动有限粒子，DPR 上限 2，无闲置绘制、无逐帧 React 更新。非模态 manual popover 位于 top layer；画布与 backdrop 均透明且不拦截指针，装饰内容不进入可访问树。
- 桌面 emoji 在每轮开始时以最高支持 DPR 的清晰度绘制到一个临时画布，逐帧通过 `drawImage` 复用；每轮结束／替换／取消释放主画布和字形画布。只修改装饰绘制，不修改完成事件或回执契约。移动端 `src/celebration.tsx` 使用系统 Text 和原生 Animated，`src/celebration-shape.ts` 集中选择本轮图案；装饰不进入可访问树，不随系统文字大小缩放。
- 粒子出生位置为 CSS 像素坐标 `(0, innerHeight)` 和 `(innerWidth, innerHeight)`；摆动在出生时为零。每侧独立分层采样发射角（22°–82°）与速度，让每轮同时包含陡、平、慢和横跨中央的粒子；位置由线性空气阻力加重力的闭式解计算（水平以窗口宽、垂直以窗口高为单位），阻力让快粒子在前半秒后趋于悬停，慢粒子留在角旁，锥形整体锚定在出生角。每侧一枚零延迟种子在首帧出现，其余延迟按三次方分布集中在头几帧、尾部持续到约 450 ms。
- 不增加动画依赖，不更改数据库、IPC、CSP、备份格式或撤销成员。渲染失败不影响保存或撤销。设置变化不重播旧事件。

## 复盘触发的实现前失败场景

- Final review confirmation celebrates before the modal closes, fires twice, or plays after a rejected/lost write; disabled review-column or reduced-motion preferences are ignored; a stale-generation request plays after replacement; cancelling motion or reloading replays the result. Observe actual Canvas corner translations through the native completion group; preserve the existing player, cleanup and item-completion path.
