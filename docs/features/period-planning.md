# 周期规划与待办右键菜单

> 右键将待办移到下一周期；点击列标题打开周期面板，统一浏览过去、本期和未来。往期任务按最新状态展示，支持编辑、完成、重开、删除和还原。

## 产品规则

- 2026-10-06 负责人确认返回动作改为日期右侧的回转箭头图标，与新建按钮同排，列头保持单行；仅非本期显示，默认无底色，悬停／键盘聚焦显示完整五语言提示。提示可用 Esc 单独关闭，原有返回当期、指针动效和键盘即时导航保留。触控图标有 44px 点击区域。标题优先完整显示，空间不足时仅次要日期省略，完整日期仍可悬停查看。

- 空列／空历史的居中短提示使用最多 280px、且不超出列内可用宽度的正文区，优化自然换行；「为这一段时间，留一个清楚的方向。」在最小 320px 列内完整显示，不把「方向」拆成孤字尾行。文案、字号和图标位置沿用现有规则。

- 本期待办的菜单文案为「移到明天」「移到下周」「移到下月」「移到下个 3个月」「移到下个半年」「移到下一年」；自然年模式对应「下季度」「明年」。相对目标日期提示省略年份。更远的目标名称按工作区今年补年份；365 天模式下年 / 半年 / 3个月按原始锚点计算，自然年模式按日历年 / 半年 / 季度。六列命名、面板与年份规则见 [双日历模式](calendar-modes.md#43-命名与年份显示d8)。
- 仅有效周期中的未完成、未归档、未删除条目可以顺延。Later、完成行、历史行无此菜单。只移动该条目，保留正文、截止日期、状态与关系；目标追加至末尾，来源不留引用。
- 顺延后保持视图并静默更新列表，不显示去向 Toast 或撤销按钮；六种尺度和继续顺延统一处理。顺延仍进入会话撤销栈，支持 ⌘Z／Ctrl+Z；主动撤销后的成功反馈及操作失败提示保留。普通拖动和新建继续静默，撤销沿用现有会话与效果字段规则。
- 看板中的顺延条目不显示「顺延」标签，也不为该标签保留占位；顺延来源数据和历史记录继续保留。
- 「设置 → 日历与顺延」只展示日历设置与到期未完成策略，移除顺延批次列表、批次明细和批次撤销入口，并停止加载这些界面数据；底层自动顺延与不可变历史继续保留。
- 六个时间列共用紧凑箭头、标题与日期（周期切换器）及返回按钮；周复盘入口在列头下方单独一行，月复盘使用统一引导卡（见[流程洞察](flow-insight.md)）；Later 不提供时间导航。本期及相邻年／半年／日／周／月用相对名称。365 天模式非本期三个月直接以日期为标题，自然年季度显示 Qn；自然年的「今年」不再附重复日期。锚定尺度面板本期按钮为「本期」（自然年年度为「今年」）。非本期显示对应尺度的返回按钮；往期编辑与历史批量处理继续保留。
- 往期页只显示目前仍属于这一期的任务，按最新状态分为「当期已完成」「当期未完成」「当期删除」。移走或顺延的任务不留引用，撤销归位后恢复显示；未删除的取消／归档任务沿用普通看板的隐藏规则。三类始终展开，分组标题紧贴首条记录，组间留白大于组内间距。
- 往期未完成／已完成任务可直接勾选和重开，点击标题可编辑、删除或移动；已删除任务可直接还原。操作成功立即更新所在分组，保留同一任务的键盘焦点。所有操作复用真实任务的版本保护、撤销和实际操作时间；今天补勾上周任务不会倒填完成日期或改写期末历史。仍不向已结束周期新建、拖入或重排任务。
- 可连续跨越过去、本期和未来；历史到达最早有记录的周期后停止向前，空周期仍能逐期跨过。列头日期统一省略年份，包含年份的完整日期可悬停查看；更远周期直接用日期作标题，不显示单独的「日／周／月／周期」，也不重复显示同一日期。锚定尺度面板的日期以工作区今年为参照：不在今年的一端补两位年份，两端同在其他年份时仅开头补一次；相对列头不带年份，自然年使用年份／半年／季度名。年与半年相邻列头使用相对名。Esc 先关闭菜单或输入，再返回本期；关闭面板后焦点回到列头标题。默认启动显示本期，选中的未来周期到期后成为本期，跨过后成为往期任务页。
- 列头 B：标题与日期是一个按钮，按内容宽度完整显示（有空间时不省略），左缘与任务复选框对齐，返回按钮紧邻其后。悬停整列时出现 ⌄ 与新建按钮，标题和日期的位置始终不变；键盘聚焦时同样可见，触控设备常显并保留 44px 点击区域。
- 点击标题打开周期面板（沿用截止日期面板的样式）：顶部为上一期／本期／下一期常用按钮，名称随尺度和模式变化，上一期有待复盘时带琥珀点。周列为按周起始排布的月历，整行框选一周；日列为月历选单天；月列为一年 12 个月的网格；年、半年、三个月列固定列出 6 期（最多含本期之前两期，其余向未来补齐），自然年年度列表显示四位年份。当前显示的周期用深底浅字标出，今天仍画圈；早于最早有记录的周期不可选；网格与列表带已记录周期的完成数，历史查询失败显示重试。六个周期面板都没有底部逐期翻页；列头 ←／→ 仍可跨过空周期。
- 选择后面板关闭、焦点回到标题；Esc 先关闭面板，再按一次返回本期。标题聚焦时 ←／→ 逐期翻页、↓ 打开面板；键盘翻页不播放动效，鼠标点选周期按时间方向滑入。
- 点击顶栏流程筛选或按有效的 ⌘/Ctrl+数字时，所有往期列自动回到当期、列表回到顶部；重复选中同一筛选也生效，未来周期及草稿保留。快捷键仍遵循[启停、空位置和输入保护](shortcuts.md)。
- 鼠标或触控翻页时，内容按时间方向从右／左滑入，220ms 内完成；返回按钮按实际时间方向过渡。导航控件保持可点击，数据就绪后只对最新选择播放一次，连续点击取消前一次动效。首次加载、后台刷新、键盘翻页及减少动态效果模式不播放；隐藏窗口或切换减少动态效果时结束动效，关系线随内容同步定位。
- 列内创建和拖动明确绑定显示周期；每周期保留未提交的输入。目标周期已过期的新建／位置写入拒绝且保留草稿，不静默改投本期；已有往期任务的内容和状态仍可修改。全局智能输入仍按现有当前周期规则工作。
- 详情显示真实周期，可从未来移回本期。关系候选、关系线及反馈使用一致的可见条目；未来位置不得标成往期。搜索打开未来任务后，关闭详情保持看板原来显示的周期；查看任务所在周期使用列头导航。
- 详情顶部 More 菜单起始边贴合按钮并向右展开；菜单浮出弹窗滚动边界，窗口空间不足时平移到可见范围。保留取消／恢复待办、归档／取消归档与回收站操作，移除「定位到看板」。Esc 只关闭菜单。
- 菜单使用 shadcn/Radix 与 Hugeicons，支持右键、Shift+F10、菜单键、Esc 和焦点恢复；不干扰拖动、链接和复选框。菜单打开时锁定虚拟行；忙碌、维护和未知结果时禁止重复写入。
- 一级和二级菜单按内容收紧，二级菜单已用具体日期命名时不重复显示日期提示；可用菜单项与子菜单入口使用手型光标。右键／键盘打开菜单后，来源任务保留激活底色与流程圆点，鼠标进入二级菜单时仍保持，菜单关闭后恢复正常状态。
- 所有新增文案覆盖中、英、日、西、法。

## 工程契约

- `create.period` 支持 `current` / `date`；`move.period` 另支持 `next`。省略表示当前周期；下一周期由权威事务从原位置计算。指定日期必须是该尺度的合法起点，目标不能已结束；保留代次、版本和位置版本保护。
- `getBoardPeriods` 只读取显式选择的当前/未来周期摘要，每种尺度至多一个，返回周期、条目、顺延来源、代次和修订。读取不创建周期，只有写入才物化。当前快照和历史查询保持独立职责。
- 视图按选择、代次、修订隔离，过时响应不进入看板；刷新完成后再解析位置反馈。详情返回实际周期。历史索引先过滤结束周期再限制条数。
- `getPastPeriod` 按当前唯一位置读取有界任务摘要，在分页和总数计算前筛选；带代次／修订校验，分页因移走任务而越界时回到最后有效页。`getHistory` 独立保留不可变的期末投影与后续活动，不把最新状态伪装成期末记录。
- 复用位置效果、原子历史、回执、撤销和现有存储结构，不做数据库迁移。过期位置的撤销仍产生 current-period hold。

## 实现前失败场景

- Return-icon correction (2026-10-06): the icon still creates another header row, loses its accessible/localized label, mixes with Undo or quick add, clips its floating hint, cannot be reached by keyboard, changes period when Escape dismisses the hint, or fails pointer/Enter return. Keep titles and controls readable at 320px, preserve full-date access when a secondary range is constrained, and retain the empty-card row and 44px touch controls.

- Return-action layout regression (2026-10-06): English and other long translations collapse to a generic “Back to…” at the 320px column minimum; preserving the action pushes the period switch or add control outside the column, hides its chevron or changes period/draft behavior. Measure native five-locale return labels, control bounds and actual return navigation, including the future-half annual-direction case.

- Detail More regression (2026-10-03): the panel remains end-aligned, clips at the dialog edge or overflows a narrow window; Escape closes both layers, the removed board-location action survives, or browsing the menu writes tasks. Search/detail close must preserve future-period selection and collapsed Later state.

- Silent advance regression (2026-09-29): advancing day/week/month/cycle or advancing again emits a success Toast, drops keyboard undo membership, restores the wrong period or overwrites later text edits. Failed advances must still explain the error.

- 日期边界错误：跨日/周/月/年、非周一起始、DST、月底三个月锚点漂移，或把未来目标强制改投本期。
- 无效写入：Later 携带周期、非法起点、已过期目标、已完成/归档/删除条目顺延、跨尺度 next、错误排序邻居、过时代次/版本。
- 重复或部分写入：连点、回执恢复、边界时刻重复操作、失败后留下周期/历史/排序变化，或撤销覆盖后续正文编辑。
- 数据丢失：未来项提前自动顺延、移走后仍留本期、重启丢失位置、草稿跨周期串用或丢失、未来数据挤掉历史索引。
- 视图竞态：快速翻页、Later 收起、工作区替换、旧请求晚到、反馈早于布局、未来完成/撤销后行未刷新。
- 输入冲突：右键变成拖拽/完成/打开链接、Esc 连续关闭两层、菜单键无效、虚拟行卸载导致菜单或焦点丢失。
- 菜单显示回归：日期重复或年份挤宽菜单、子菜单沿用过大的最小宽度、可点击项缺少手型光标、鼠标移入菜单后来源行失去激活底色／圆点，或关闭后错误保留激活态、覆盖流程底色和其他行状态。
- 界面不一致：详情/搜索/定位显示错误周期、未来误标往期、未来行不参与流程、主题或语言漏译。
- 统一浏览回归：从未来回到本期后不能继续向前、空周期阻断导航、箭头远离文案、复盘落到箭头外或下一行、悬停导致布局跳动、键盘或触控下导航不可见、翻页焦点丢失、旧周期响应覆盖新周期、往期操作误改期末投影或拖入已结束周期、历史折叠隐藏或分页漏项、分组标题与记录间距过大、返回本期导致未来草稿丢失。
- 列头与动效回归：非本期日期掉到第二行、返回标签与尺度不符、远期标题重复日期或显示年份挤占列头；滑入方向反转、数据未就绪就播完、连续点击排队或旧动效覆盖新内容、动效造成水平溢出或关系线脱离、键盘／减少动态效果下仍移动、窗口隐藏后继续占用动画资源。
- 标题对齐回归：隐藏箭头仍占据正文起点、标题与复选框左缘错位、左箭头与流程圆点不在同一条竖线上、悬停／键盘聚焦时标题跳动，或左箭头跨出本列、覆盖标题和相邻列控件。
- 列头 B 回归：有空间时标题仍被省略、面板选中与显示周期不一致、整周框选落到错误周起始、往期越过最早记录、选择后焦点丢失、Esc 同时关闭面板并返回本期、键盘翻页播放动效。
- 往期编辑回归：补勾或重开后分组不变、删除／还原后仍使用旧版本、已移走任务仍可操作、分页最后一项移走后落入空页、分组变化丢失键盘焦点、加载／维护中重复操作、旧代次或旧响应覆盖当前页面、还原反馈误报不可见、改写真实完成时间或原始期末投影。
- 筛选返回回归：仅重置一列、重复快捷键未返回、色块重排后选错流程、列表停在历史滚动位置、误清未来周期／草稿、禁用或空位置快捷键仍导航、输入和弹窗内误触发、旧历史请求返回后重新显示往期。
