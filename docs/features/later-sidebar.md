# Later 固定侧栏

> Later 是独立暂存区：固定左侧、默认展开，顶部「托盘图标 + Later + 数量」按钮控制展开。

## 产品规则

- 「全部」左侧的文字胶囊按钮（Hugeicons 托盘图标 + 「Later」+ 数量）独立控制 Later：收起时细描边，展开时加深底色；数量为未完成且未归档／未删除的总数；零值不显示数字，不受流程筛选影响；作为顶栏最左的位置占用 ⌘1（与筛选数字键共用开关）。
- Later 是停靠在左侧、带圆角与轻阴影的抬升面板（自身底色区别于时间列），仍推开时间区而非浮层；面板宽度与可见时间列一致，保留标题、新建、虚拟待办列表及已完成折叠组。时间列与 Later 共用 320px 最小宽度、不设上限，各自纵向滚动，只有放不下时才出现仅覆盖右侧的横向滚动条。
- 展开状态保存在本机，不进入工作区、历史、备份或导出。时间列显隐由[独立列菜单](column-visibility.md)控制，与 Later 互不覆盖；旧 `goalloom.hiddenColumns` 的时间列值仍忽略，保留 Later 原有展开状态。
- 收起保留新建草稿、纵向滚动和完成分组状态，同时禁止隐藏内容接收焦点或拖放；内部焦点交回顶部按钮。普通展开不抢焦点。搜索仍可打开已收起的 Later 条目详情，关闭详情保持收起且不聚焦隐藏任务。
- 两块区域共享鼠标／键盘拖放及撤销；时间列仍按显示中的当前／未来周期接收任务。Later 不参与新建关联。移入 Later 时，在同一次可撤销操作里解除该条目的全部上级，复选框不再使用流程色；它作为上级留下的下级关联继续保留。在 Later 内部改顺序不解除这些下级。撤销这次移入会一起恢复上级和原来的位置。
- Later 行没有流程圆点，不为圆点留出 20px；行首仍留 12px，避免复选框贴边。列标题、新建和完成分组与这颗复选框对齐。时间列仍保留圆点留白。
- 展开 240ms、收起 180ms，以 transform 平移侧栏和时间区，不缩放文字。连续切换从当前位置接续；初始加载、减少动态效果及隐藏窗口直接定位。开始拖动时结束布局动画并更新碰撞测量。
- 五种语言提供展开／收起和剩余数量的无障碍提示；纸感／简约及明暗主题共用现有视觉变量。

## 工程契约

- `useColumns` 沿用 `goalloom.hiddenColumns` 读取及写入 Later 状态，忽略其中的旧时间列隐藏值；时间列使用独立偏好，契约见[列显隐规格](column-visibility.md)。`App` 从权威快照派生计数；详情关闭不改变侧栏状态，无新增 IPC 或数据库字段。
- `BoardLayout` 保持 Later 的 Column 身份及内容挂载，收起使用 inert 和不可见状态。WAAPI 配合已有有限 `boardMotionEvent` 更新几何，结束／打断／卸载清理动画。
- `geometry` 为拖放、连线、断点及保存反馈提供统一面板视口。横向被裁剪的时间列不能抢占 Later 的投放；同面板连线按面板裁剪，跨 Later 连线不得连接到被横向遮住的端点。

## 失败场景与验收

- 零值误显示、筛选改变数量、状态／移动／撤销后数量不刷新。
- 列显隐菜单错误包含 Later；旧隐藏偏好导致时间列缺失，或调整时间列时重置 Later 状态。
- 侧栏随横向滚动移动、窄窗口挤出主视口、滚动条跨越侧栏；关闭时丢失草稿、滚动或完成分组状态。
- 隐藏任务仍能聚焦／接收拖放、横向遮住的时间列抢占命中、空列或未来周期拖放错误；搜索后关闭详情意外展开侧栏或聚焦隐藏任务。
- Later 行仍为流程圆点预留整段空白，或复选框贴着行的左缘，或列标题与复选框错位。移入 Later 后仍保留上级，或复选框继续使用流程色。撤销移入只恢复位置；在 Later 内排序，或把仍有下级的条目移入 Later 时，误删下级。
- 动画重入闪跳、缩放文字、减少动态效果仍播放、线或断点漂移、收起内容被判为可见。
