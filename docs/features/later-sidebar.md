# Later 固定侧栏

> Later 是独立暂存区：固定左侧、默认展开，顶部按钮显示未完成数量。

## 产品规则

- 「全部」左侧的 Hugeicons 侧栏按钮独立控制 Later，显示未完成且未归档／未删除的总数；零值不显示数字，不受流程筛选影响，也不占用数字筛选快捷键。
- Later 固定 300px，保留标题、新建、虚拟待办列表及已完成折叠组。右侧四个时间列保持 356–440px，各自纵向滚动，共用仅覆盖右侧的横向滚动条。
- 展开状态保存在本机，不进入工作区、历史、备份或导出。四个时间列固定显示，不提供列显隐调整入口；旧偏好隐藏的时间列恢复显示，保留 Later 原有展开状态。
- 收起保留新建草稿、纵向滚动和完成分组状态，同时禁止隐藏内容接收焦点或拖放；内部焦点交回顶部按钮。普通展开不抢焦点，明确定位 Later 条目时展开并聚焦目标。
- 两块区域共享鼠标／键盘拖放及撤销；时间列仍按显示中的当前／未来周期接收任务。Later 不参与新建关联，移动留下的既有关联继续保留。
- 展开 240ms、收起 180ms，以 transform 平移侧栏和时间区，不缩放文字。连续切换从当前位置接续；初始加载、减少动态效果及隐藏窗口直接定位。开始拖动时结束布局动画并更新碰撞测量。
- 五种语言提供展开／收起和剩余数量的无障碍提示；纸感／简约及明暗主题共用现有视觉变量。

## 工程契约

- `useColumns` 沿用 `goalloom.hiddenColumns`，只读取及写入 Later 状态，忽略旧时间列隐藏值；固定派生四个时间列，不暴露调整接口。`App` 从权威快照派生计数，定位 Later 条目时展开侧栏，无新增 IPC 或数据库字段。
- `BoardLayout` 保持 Later 的 Column 身份及内容挂载，收起使用 inert 和不可见状态。WAAPI 配合已有有限 `boardMotionEvent` 更新几何，结束／打断／卸载清理动画。
- `geometry` 为拖放、连线、断点及保存反馈提供统一面板视口。横向被裁剪的时间列不能抢占 Later 的投放；同面板连线按面板裁剪，跨 Later 连线不得连接到被横向遮住的端点。

## 失败场景与验收

- 零值误显示、筛选改变数量、状态／移动／撤销后数量不刷新。
- 已删除的列显隐入口仍在某语言中出现；旧隐藏偏好导致时间列缺失，或恢复时间列时重置 Later 状态。
- 侧栏随横向滚动移动、窄窗口挤出主视口、滚动条跨越侧栏；关闭时丢失草稿、滚动或完成分组状态。
- 隐藏任务仍能聚焦／接收拖放、横向遮住的时间列抢占命中、空列或未来周期拖放错误；定位隐藏任务失败。
- 动画重入闪跳、缩放文字、减少动态效果仍播放、线或断点漂移、收起内容被判为可见。
