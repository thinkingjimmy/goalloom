# 快捷键

> 本机键位偏好：通用快捷键可在「设置 → 快捷键」修改；顶栏按钮（Later、全部、流程）按位置用 ⌘/Ctrl+数字，一个开关整体启停。

## 产品规则

- Later 按钮是顶栏最左的位置，占 ⌘1（Windows Ctrl+1），用来展开／收起 Later；它与筛选共用「顶栏数字键」开关，不再单独设置快捷键。

- 默认键位：打开搜索与命令 ⌘K、新建 ⌘N、打开设置 ⌘,、撤销 ⌘Z、保存/确认 ⌘↵（仅新建与条目详情；新建里单独 ↵ 同样执行主操作，⇧↵ 换行）。Windows 上 ⌘ 显示为 Ctrl。Mod 严格按平台匹配，不合并额外的 Control/Meta；macOS Ctrl+K 保留输入框原生删除到行尾行为。
- 流程筛选按顶栏位置，与浏览器标签一致：⌘1 = Later，⌘2 = 全部，⌘3…⌘9 = 顶栏从左到右的第 1…7 个未归档流程（流程最多 8 个，第 8 个没有数字键）。重复按当前位置保留所选流程；该位置没有流程时不响应。筛选键不可逐个改键，只有「用 ⌘ + 数字切换顶栏筛选」一个开关（默认开）；设置里用不含真实流程名的示意图说明位置对应关系。
- 主动点击顶栏筛选或使用有效的筛选快捷键时，所有正在查看往期的列回到当期并回到列表顶部，包括重复选择当前筛选或「全部」。未来周期与其草稿保持不变。数字键先按按下时的顶栏位置确定流程身份，再返回当期；返回导致色块重排也不改变选中的流程。禁用、空位置、输入框和弹窗拦截的快捷键不改变周期。
- 顶栏覆盖各列的流程起点，按看板阅读顺序排列：同列从上到下（待办在已完成之前），再向右进入下一列。目标重排、跨列移动、完成/撤销及当前/未来周期切换后，色块与数字快捷键自动同步；已选流程按身份保持。Later 收起／展开不改变流程顺序；不在当前显示周期内的未归档流程保留在末尾，沿用原有稳定顺序。
- 看板快捷键在详情、设置、composer、搜索弹窗打开时或 Onboarding 期间不生效；新建/设置/筛选在输入框中不生效；搜索仍可在输入框中用 ⌘K（Windows Ctrl+K）打开；撤销在输入框外任意位置可用；上一个写入尚未落定时按下的撤销不会丢弃，落定后执行一次（维护中或结果未知时不执行）；IME 组字期间不触发任何快捷键。
- Todo 详情关闭后，焦点回到对应标题，保留虚拟行与键盘续接。鼠标打开时，无论 Esc 或关闭按钮退出，都不因焦点返回出现蓝色描边；后续键盘输入恢复正常焦点提示。键盘打开与 Tab 导航继续显示焦点提示。普通与链接标题、四种主题一致；纯打开／关闭不写任务数据。
- Todo 详情标题的原生文本撤销／重做保留至本次详情关闭，自动保存与退出／重新编辑不会清除。标题清空后，焦点在详情内非文本控件上时，⌘Z／Ctrl+Z 优先恢复标题草稿并返回标题编辑；说明等其他输入框仍使用自己的文本撤销。
- 标题清空且没有其他有效数据的待办，关闭详情后直接移除，不进入回收站；此时 ⌘Z／Ctrl+Z 使用会话撤销，一步恢复最后保存的原标题和原位置。关闭前仍使用原生文本撤销；有其他数据的条目继续保留详情与输入校验。
- 改键：点击行尾键帽进入录制，按下新组合即保存；Esc 或点击别处取消，录制期间不触发全局快捷键、不关闭弹窗。组合必须包含 ⌘/Ctrl 或 ⌥/Alt；复制/粘贴/剪切/全选与默认菜单占用的组合（退出、关闭、隐藏、最小化、重载、缩放、开发者工具、重做）会被拒绝并行内提示。
- 相同按键的快捷键显示警告图标并列出冲突对象（通用键落在已启用的 ⌘1…⌘9 上时冲突对象为「顶栏数字键」），不阻止保存（仅在特定弹窗生效的快捷键可以合理共用）。可清除单个快捷键（未设置），页头「恢复默认」清除全部自定义并重新打开流程筛选。
- 录制方法与按键复用、冲突规则的说明统一放在「快捷键」标题下方；冲突说明随语言和可用宽度完整换行，正文底部不再重复。
- 按物理键识别（Shift、输入法与键盘布局不改变 ⌘2 的含义）。

## 工程契约

- `src/renderer/state/shortcuts.ts` 是唯一来源：定义表、按位置的 `filterCombo`/`filterSlot`、解析/校验/格式化、`useShortcuts` 外部存储。只保存与默认不同的项到 localStorage `goalloom.shortcuts`（改过的通用键，及关闭筛选时的 `filters: false`）；非法或未知项在读取时丢弃并回退默认。键位不进入工作区数据、历史、导出或备份。
- `App.tsx` 统一分发全局快捷键；顶栏与筛选快捷键共用主动选择入口，调用 `useBoardPeriods.returnPastToCurrent` 原子清除往期选择，内部筛选清理不触发导航。composer 的确认与详情的立即保存并结束编辑读取同一绑定；详情平时自动保存，无需按快捷键；顶栏、FAB、Toast、命令面板的快捷键提示随绑定变化，`aria-keyshortcuts` 同步。
- `state/flows.ts` 从 `useBoardPeriods.items` 派生 `visible`：复用看板摘要顺序、固定列序与待办/完成分组；顶栏与快捷键共用同一列表。位置变化只重算展示顺序，不重建图归属与颜色缓存，不额外保存筛选顺序。
