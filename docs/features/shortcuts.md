# 快捷键

> 本机键位偏好：通用快捷键可在「设置 → 快捷键」修改；顶栏流程筛选用 ⌘/Ctrl+数字，一个开关整体启停。

## 产品规则

- 默认键位：打开搜索与命令 ⌘K、新建 ⌘N、打开设置 ⌘,、撤销 ⌘Z、保存/确认 ⌘↵（仅新建与条目详情；新建里单独 ↵ 同样执行主操作，⇧↵ 换行）。Windows 上 ⌘ 显示为 Ctrl。Mod 严格按平台匹配，不合并额外的 Control/Meta；macOS Ctrl+K 保留输入框原生删除到行尾行为。
- 流程筛选按顶栏位置，与浏览器标签一致：⌘1 = 全部，⌘2…⌘9 = 顶栏从左到右的第 1…8 个未归档流程（流程最多 8 个）。重复按当前位置不切换；该位置没有流程时不响应。筛选键不可逐个改键，只有「用 ⌘ + 数字切换顶栏筛选」一个开关（默认开）；设置里用不含真实流程名的示意图说明位置对应关系。
- 看板快捷键在详情、设置、composer、搜索弹窗打开时或 Onboarding 期间不生效；新建/设置/筛选在输入框中不生效；搜索仍可在输入框中用 ⌘K（Windows Ctrl+K）打开；撤销在输入框外任意位置可用；IME 组字期间不触发任何快捷键。
- 改键：点击行尾键帽进入录制，按下新组合即保存；Esc 或点击别处取消，录制期间不触发全局快捷键、不关闭弹窗。组合必须包含 ⌘/Ctrl 或 ⌥/Alt；复制/粘贴/剪切/全选与默认菜单占用的组合（退出、关闭、隐藏、最小化、重载、缩放、开发者工具、重做）会被拒绝并行内提示。
- 相同按键的快捷键显示警告图标并列出冲突对象（通用键落在已启用的 ⌘1…⌘9 上时冲突对象为「流程筛选」），不阻止保存（仅在特定弹窗生效的快捷键可以合理共用）。可清除单个快捷键（未设置），页头「恢复默认」清除全部自定义并重新打开流程筛选。
- 按物理键识别（Shift、输入法与键盘布局不改变 ⌘2 的含义）。

## 工程契约

- `src/renderer/state/shortcuts.ts` 是唯一来源：定义表、按位置的 `filterCombo`/`filterSlot`、解析/校验/格式化、`useShortcuts` 外部存储。只保存与默认不同的项到 localStorage `goalloom.shortcuts`（改过的通用键，及关闭筛选时的 `filters: false`）；非法或未知项在读取时丢弃并回退默认。键位不进入工作区数据、历史、导出或备份。
- `App.tsx` 统一分发全局快捷键；composer 与详情的保存/确认读取同一绑定；顶栏、FAB、Toast、命令面板的快捷键提示随绑定变化，`aria-keyshortcuts` 同步。
