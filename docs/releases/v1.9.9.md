# Goalloom 1.9.9

## Improvements

- **Change task levels while editing.** Double-click a task title on the board, then press Tab to place it under the preceding task. Shift+Tab makes it independent. Your text, selection and focus stay in the editor. Level changes support undo without replacing later text edits.
- **Schedule subtasks independently.** A subtask keeps its parent when moved to another planning column or period. The board shows its parent without duplicating the parent card. Moving a parent carries only subtasks scheduled with it; moving an individual subtask across the Later boundary makes it independent.
- **Keep chosen positions during sync.** Newly created tasks retain their placement and order when encrypted changes are replayed, including manual insertion and immediate or delayed goal matching.

## Update

Workspace format remains v11. Updates preserve the app identity, local data location, tasks and settings. macOS downloads are Developer ID signed and notarized by Apple; Windows installers remain unsigned.

Update every computer using sync to 1.9.9 before scheduling subtasks independently across columns or periods.

If updating from 1.9.7 or earlier, also follow the production-sync transition instructions in the [1.9.8 release notes](https://github.com/thinkingjimmy/goalloom/releases/tag/v1.9.8). The published macOS 1.8.0 build requires one manual replacement in Applications.

## 改进

- **编辑标题时切换任务层级。** 在看板上双击任务标题后，按 Tab 归入前一项任务，按 Shift+Tab 恢复一级。文字、选区和焦点留在输入框中；层级变化支持撤销，保留之后的文字修改。
- **子任务可以独立排期。** 子任务移到其他计划列或周期后，仍保留所属任务。看板提供所属任务入口，不重复显示父任务卡片。移动父任务时只带走与它排在同一位置的子任务；单独移动子任务跨越 Later 边界时，会恢复为独立任务。
- **同步保留新建位置。** 加密变更重放时，保留新建任务的位置和顺序，包括手动插入、即时目标匹配及稍后完成的目标匹配。

## 更新

工作区格式保持 v11。升级保留应用身份、本地数据目录、任务和设置。macOS 安装包使用 Developer ID 签名并通过 Apple 公证；Windows 安装包仍未签名。

使用跨列或跨周期的子任务独立排期前，请将参与同步的电脑均升级到 1.9.9。

从 1.9.7 或更早版本升级时，还需遵循 [1.9.8 发布说明](https://github.com/thinkingjimmy/goalloom/releases/tag/v1.9.8)中的生产同步迁入步骤。公开版 macOS 1.8.0 需手动替换「应用程序」中的旧版一次。
