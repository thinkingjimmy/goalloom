# Goalloom 1.9.6

## Upgrade all synced computers

Before continuing edits, upgrade every computer sharing a sync workspace to 1.9.6. This version adds information needed to distinguish concurrent changes. Older clients cannot read new operations and will stop receiving them until upgraded. Do not downgrade a synced workspace after using this version.

Update through Settings → About, or install over the existing app. Workspace format v11, your application identity, data directory and saved sync session stay unchanged. This update does not require a sync password reset or a new account.

## Improvements

- **Compare familiar task cards.** A quiet notice opens a separate dialog when local changes need your decision. Compare this computer's changes with the synced result side by side. Differences are highlighted using the board's task appearance.
- **Choose, then continue.** Radio buttons are the only choice. The synced result is selected by default. Multiple changes to one task form one step. Next confirms the current task; Finish returns directly to the board. You can defer unfinished decisions.
- **Keep confirmations after signing in again.** Confirmed differences stay confirmed through sign-out, sign-in and restarts. Retries do not apply the same decision twice. Changes that are already present do not generate another warning.
- **Keep deletions unless you choose recovery.** The default leaves a deleted task deleted. Explicit local recovery restores only the selected task. A rejected offline-created task and its later edits can be kept as an independent task without recreating a deleted parent.
- **Protect newer edits.** A decision preserves unrelated changes. If the compared values change before confirmation, the old decision cannot overwrite them. Concurrent edits require review; ordinary later edits do not.

macOS downloads are Developer ID signed and notarized by Apple. Windows installers remain unsigned. The published macOS 1.8.0 build requires one manual replacement in Applications; your workspace and settings are kept.

## 请一起升级同步中的电脑

继续编辑前，请将同一同步空间的所有电脑升级到 1.9.6。本版增加了识别并发修改所需的信息。旧客户端无法读取新版操作，升级前会停止接收这些操作。使用本版后，请勿将同步空间降级到旧版。

可在「设置 → 关于」更新，或覆盖安装。工作区格式仍为 v11，应用身份、数据目录和已保存的同步会话保持不变。本次更新不需要重置同步密码或重新注册。

## 改进

- **用熟悉的任务卡片比较差异。** 本地修改需要确认时，轻提示会打开独立弹窗。左右查看这台电脑的修改与同步后的结果，沿用看板任务样式，并标出差异。
- **选择后继续下一项。** 仅保留单选操作，默认使用同步后的结果。同一任务的多处修改合为一步。「下一项」确认当前任务；最后点击「完成」直接返回看板。未处理的差异可以稍后继续。
- **重新登录后保留确认结果。** 已确认的差异不会在退出、登录或重启后再次要求处理。失败重试不会重复应用相同选择。已经存在的修改不再重复提醒。
- **默认保留删除结果。** 已删除的任务默认保持删除；主动选择恢复时，仅恢复所选任务。离线新建任务因上级被删而未同步时，可将该任务及其后续修改保留为独立任务，不会恢复已删除的上级。
- **保护后续修改。** 确认只应用相关差异，保留其他修改。比较内容在确认前变化时，旧选择不能覆盖新值。并发修改需要确认，正常的后续修改不会触发冲突提醒。

macOS 安装包通过 Developer ID 签名和 Apple 公证；Windows 安装包仍未签名。公开版 macOS 1.8.0 需手动替换「应用程序」中的旧版一次，工作区与设置会保留。
