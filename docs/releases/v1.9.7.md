# Goalloom 1.9.7

## Improvements

- **Create subtasks as you type.** In a column's inline entry, press Tab to place the draft under the preceding task, then Enter to save. Continue entering siblings under the same task. Shift+Tab returns to an independent task. Text, cursor position and drafts are preserved. This works in current and future periods and Later.
- **Move complete groups together.** Drag a task with children onto another task to place the source and its children directly under that task, in their existing order. Child-edge insertion and keyboard menus follow the same rule. One undo restores the original group.
- **See what AI suggests.** Inline entry shows matching progress, the suggested column and goals, and retry or resend actions when needed. Enter still saves immediately. Manual choices and later edits take priority over delayed replies.
- **Match work to broader goals.** Features, fixes, UX improvements and validation can match the same product's development or version goal without repeating the version number. Explicitly different projects or versions remain separate.
- **Keep column controls together.** More sits beside Add at the right of each column header. Hover or keyboard focus reveals both controls; touch controls stay visible. Independent inline entry has less keyboard-hint clutter.

Nested creation, undo, scoped restore, backups and encrypted sync retain the task's group and sibling order. Failed or delayed saves preserve the current draft.

## Update

Update through Settings → About, or install over the existing app. Upgrade all computers sharing a sync workspace to 1.9.7. Workspace format remains v11. Application identity, data location and saved sync sessions are preserved.

macOS downloads are Developer ID signed and notarized by Apple. Windows installers remain unsigned. The published macOS 1.8.0 build requires one manual replacement in Applications; your workspace and settings are kept.

## 改进

- **输入时直接创建二级任务。** 在列内输入框按 Tab，将草稿归入前一项任务，再按 Enter 保存。可以连续输入同级子项；Shift+Tab 返回独立任务。文字、光标位置和草稿会保留，适用于当前周期、未来周期和 Later。
- **整组任务一起归入。** 将带子项的任务拖到另一项任务上，会按原顺序把该任务及其子项直接归入目标下。子项边缘插入和键盘菜单遵循同一规则，一次撤销可恢复原有分组。
- **看见 AI 的匹配建议。** 列内输入显示匹配进度、建议时间列和目标，并在需要时提供重试或重新发送。Enter 仍会立即保存，手动选择和后续编辑优先于迟到的回复。
- **更准确地匹配开发目标。** 同一产品的功能、修复、体验改进和验证任务，可匹配到更广的开发或版本目标，无需重复版本号。明确属于其他项目或版本的任务仍会分开。
- **列头操作集中显示。** 「更多」与「添加」并列放在列头右侧，悬停或键盘聚焦时一起显示，触控设备保持可见。独立任务输入移除了多余的键盘提示。

二级任务的新建、撤销、还原、备份和加密同步会保留分组及同级顺序。保存失败或回复延迟时，会保留当前草稿。

## 更新

可在「设置 → 关于」更新，或覆盖安装。请将同一同步空间的所有电脑升级到 1.9.7。工作区格式保持 v11，应用身份、数据目录和已保存的同步会话保持不变。

macOS 安装包通过 Developer ID 签名和 Apple 公证；Windows 安装包仍未签名。公开版 macOS 1.8.0 需手动替换「应用程序」中的旧版一次，工作区与设置会保留。
