# Goalloom 1.9.4

## Improvements

- **Safer sign-out on shared computers.** Keep local tasks is selected by default. You can explicitly clear local tasks, history, internal backups and sync credentials before handing the computer to someone else. Independent AI credentials and device preferences remain on the computer, as the dialog explains. Cancelling keeps your session and returns keyboard focus.
- **Account switching protects your board.** A different account cannot upload a workspace bound to your previous account. Clear local tasks first to connect another account and download its own board.
- **Forgotten sync passwords no longer require deleting the old cloud workspace.** Create a separate cloud workspace with a new password while keeping your local board. Other computers can continue using the preserved workspace. Each computer remembers its own workspace after restart, and interrupted creation retries do not create duplicates. The destructive reset remains a separate action with an exact confirmation phrase and affects only the selected workspace.
- **Sync resumes when connectivity returns.** Offline startup, network restoration and resume reconnect a saved session and upload pending changes automatically. Realtime reconnection and heartbeat checks retain polling as a fallback. Upload limits still apply, while downloads remain available.
- **Clearer recovery in all five languages.** Settings and first-run recovery explain the safe choice, the effect of clearing local tasks and how another unlocked computer can help.

## Upgrade

Update through Settings → About, or install over the existing app. Version 1.9.4 keeps workspace format v11. Existing v11 workspaces need no format conversion; v8–v10 workspaces retain the verified protective-backup upgrade introduced in 1.9.3. Your workspace, settings and app identity stay in place.

macOS downloads are Developer ID signed and notarized by Apple. Windows installers remain unsigned. If you still use the published macOS 1.8.0 build, quit Goalloom and manually replace it with 1.9.4 in Applications once; your workspace and settings are kept.

## 改进

- **共用电脑时，退出更安全。** 默认选中「保留本地任务」。交给其他人使用前，可以明确选择清除本地任务、历史、内部备份和同步凭据。独立的 AI 凭据与设备偏好仍留在电脑上，弹窗会说明保留范围。取消退出会保留登录状态，并返回原来的键盘焦点。
- **切换账号时保护现有看板。** 已绑定原账号的本地工作区不能上传到另一个账号。先清除本地任务，再连接其他账号并下载其自己的看板。
- **忘记同步密码，不必删除旧云端空间。** 可以设置新密码，创建独立的云端工作区，并保留当前本地看板。其他电脑仍可继续使用原来的工作区；每台电脑重启后会回到各自的空间，中断后重试也不会重复创建。删除并重建仍是单独的危险操作，需要输入完整确认文字，且只影响选中的云端工作区。
- **网络恢复后自动继续同步。** 离线启动、恢复网络或唤醒后，会自动恢复已保存的会话并补传修改。实时连接重连与心跳检查保留轮询后备；上传限制继续生效，下载仍可使用。
- **五语言恢复说明更清楚。** 设置与首次配置中的恢复入口明确说明安全选项、清除本地任务的范围，以及如何借助另一台已解锁的电脑恢复。

## 升级

可在「设置 → 关于」更新，或覆盖安装。1.9.4 保持工作区格式 v11；已有 v11 工作区无需转换，v8–v10 工作区继续使用 1.9.3 引入的保护备份与校验升级流程。工作区、设置和应用身份保持不变。

macOS 安装包通过 Developer ID 签名和 Apple 公证；Windows 安装包仍未签名。若仍在使用公开版 macOS 1.8.0，请先退出 Goalloom，再手动用 1.9.4 替换「应用程序」中的旧版一次，工作区与设置会保留。
