# Goalloom 1.8.0

Desktop release notes for the version after 1.7.0. Installers, update feeds and SHA256SUMS are not attached to this file. The release stays pending until those assets are published.

## Upgrade

**The workspace format stays schema v10.** A 1.7.0 workspace opens directly. Tasks, notes, history, calendar and appearance stay in the same file.

**工作区格式仍是 schema v10。** 1.7.0 的工作区直接打开。任务、说明、历史、日历和外观都留在同一份文件里。

**From 1.6.0 you can upgrade in place.** Opening a 1.6.0 workspace (schema v8) first creates and verifies an automatic protective backup, then upgrades that same workspace file to schema v10. If the backup or the upgrade fails, the original file stays on the old version. A v10 workspace cannot be opened by 1.6.0 or earlier. To return to the pre-upgrade data, restore the protective copy from the new version under Settings & data → Backups.

**1.6.0 可直接升级。** 打开 1.6.0 工作区（schema v8）时，会先自动创建并校验保护备份，再把同一份工作区文件升级到 schema v10。备份或升级失败时，原文件保持旧版本。v10 工作区不能再用 1.6.0 或更早版本打开。若要回到升级前的数据，请在新版本的「设置与数据 → 备份」里恢复保护副本。

**1.5.0 and earlier** still use the existing confirmed upgrade: the app creates and verifies a protective copy, then asks you to confirm before it replaces the workspace. Cancelling keeps the original file. The upgraded workspace is schema v10. Keeping a JSON export before you update is still a good idea.

**1.5.0 及更早版本**仍走现有的确认升级：先创建并校验保护副本，再经明确确认后替换工作区。取消则保留原文件。升级后的工作区是 schema v10。升级前仍建议自己留一份 JSON 导出。

Two-level tasks from the [1.7.0 notes](./v1.7.0.md) are in this version. 1.7.0 itself was not published.

看板上的两级任务见 [1.7.0 发布说明](./v1.7.0.md)，包含在这个版本里。1.7.0 本身没有发布。

## What's new

- **Sync is optional.** Settings → Sync. The board works while you are signed out, and it works when sync is not configured.
- **Sign in with Google.** The system browser completes sign-in. Two computers on the same Google account share one encrypted workspace, including nested tasks, offline edits and conflicts. Signing out on this computer leaves the other computer signed in.
- **A 24-word recovery key.** The first computer creates 24 English words and shows them once. Confirm the three requested words, then enter the same words on the second computer. Without that key, another computer cannot open this encrypted data.
- **End-to-end encrypted.** Task text is encrypted on the computer before it is sent. Goalloom does not add accounts that can read the board, and there is no payment step.
- **The anon key stays on your machine.** Sync needs the Supabase anon key in the environment variable `GOALLOOM_SUPABASE_ANON_KEY`, or in `sync-config.json` in the app user-data directory (`~/Library/Application Support/Goalloom/` on macOS, `%APPDATA%\Goalloom\` on Windows). The file may also set `url`. Without the key, Sync stays unconfigured and the board stays local.
- **A second computer that already has items asks first.** Leave the acknowledgement unchecked until you mean it. You can export JSON, then choose “use the other computer’s board” or “merge both sides”. Replacing or merging writes a protective backup first.

## Fixes

- A task added while replace or merge is waiting on the network is kept. The board on this computer does not change until that step finishes in one transaction.
- A long note can sync. If one change cannot be sent, changes from the other computer still arrive, and this board refreshes.
- Tasks merged onto a different calendar stay on the period you can see, instead of remaining in the file and disappearing from the board.
- Signing in with a different Google account does not replace the keys already stored for the account on this computer. A sign-in that does not finish returns to the sign-in button.
- A sync key file that cannot be unlocked stays locked and is not overwritten. The board still works.

## 更新说明

- **同步是可选的。** 在「设置 → 同步」。未登录、或还没有同步配置时，看板照常使用。
- **使用 Google 登录。** 系统浏览器完成登录。同一 Google 账号的两台电脑共享一份加密工作区，包括二级任务、离线修改和冲突。在这台电脑退出登录，另一台仍保持登录。
- **24 个单词的恢复密钥。** 第一台电脑生成 24 个英文单词，只显示一次。确认其中三个指定的单词后，在第二台电脑输入同一串单词。没有这把密钥，另一台电脑无法打开这些加密内容。
- **端到端加密。** 任务内容在离开这台电脑之前就已经加密。没有可以阅读看板的账号，也没有付款步骤。
- **anon key 留在你的电脑上。** 同步需要把 Supabase anon key 放在环境变量 `GOALLOOM_SUPABASE_ANON_KEY`，或应用用户数据目录里的 `sync-config.json`（macOS 为 `~/Library/Application Support/Goalloom/`，Windows 为 `%APPDATA%\Goalloom\`）。这个文件也可以写 `url`。没有这把 key 时，同步保持未配置，看板仍只在本机。
- **第二台电脑上已有条目时会先问你。** 确认框默认不勾选。可以先导出 JSON，再选「使用另一台电脑的看板」或「合并两边的条目」。替换或合并之前会先写一份保护备份。

## 修复

- 替换或合并还在等网络时新加的任务会保留。这一步在同一个事务里完成之前，这台电脑上的看板不会被换掉。
- 较长的说明可以同步。某一条改动发不出去时，另一台电脑的改动仍会到达，这块看板会刷新。
- 合并到另一套日历上的任务会落在你能看到的周期里，而不是留在文件里、却从看板上消失。
- 用另一个 Google 账号登录，不会换掉这台电脑上已有账号的密钥。登录没有完成时，会回到登录按钮。
- 打不开的同步密钥文件保持锁定，不会被覆盖。看板仍可使用。
