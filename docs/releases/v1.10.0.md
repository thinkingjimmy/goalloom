# Goalloom 1.10.0 for macOS

## English

- **Account and Plus controls.** Sign in with Apple or Google without starting sync. Where Plus is available, check eligibility, start the one-time eight-day trial and manage a monthly or annual subscription in the browser. Returning to the app checks the account's actual status.
- **Keep local work available.** Subscription changes pause cloud services without removing local tasks or your own AI keys. Supported cloud copies can be downloaded, inspected and exported during the recovery period shown in Settings.
- **Protected sessions and cloud setup.** Sessions use noninteractive protected storage. Explicit cloud setup keeps a verified local backup and preserves pending changes through the confirmed transition.

This release is for macOS 14 or later on Apple silicon. The app and DMG are Developer ID signed and notarized. Windows remains on 1.9.10; this release does not update or verify Windows.

Updating from 1.9.10 keeps the app identity, data folder, tasks and settings. The workspace format advances from 11 to 14, with a verified protective backup before the upgrade. Use the same account and sync password. Some older cloud workspaces cannot be restored automatically; keep your local tasks and backups. Signing in again does not restore an unsupported cloud copy. Returning to 1.9.10 requires a separate data-recovery decision after the upgrade.

## Español
