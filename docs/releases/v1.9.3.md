# Goalloom 1.9.3

## Improvements

- **Enter saves immediately.** Jev no longer blocks task creation. A ready preview is saved at once; a pending result can later fill the new task's column and goal links. Inline entry keeps its chosen column and period. Your manual changes take priority.
- **More precise goal matching with Jev 1.14.** Matching considers each candidate's action and outcome, preserves independent parents, removes redundant ancestors, and treats URLs as input data. Creation and its automatic completion remain one undo step, including encrypted synchronization between computers.
- **Less work while sync is idle.** Unchanged status checks no longer fetch the roster or operation log. Healthy background connections check less often; returning to the app checks immediately. Upload retries and waiting states leave downloads available and retain pending changes.
- **Consistent controls across the app.** Setup, Settings, task menus, drafting and reviews share the same buttons, fields, selection controls and layout rules in all five languages.

## Upgrade

Update from 1.9.0–1.9.2 through Settings → About, or install over the existing app. The workspace format advances to v11. Goalloom creates and verifies a protective backup before upgrading a v8–v10 workspace; tasks, settings and history stay in place. Older workspace formats retain the confirmed recovery flow. Older apps cannot open a v11 workspace; use the pre-upgrade protective backup if you need to return.

macOS credentials continue to use noninteractive Keychain access, including first use and restoration. Inaccessible credentials stay encrypted while the local board remains usable. macOS downloads are Developer ID signed and notarized by Apple; Windows installers remain unsigned.

**If you still use the published macOS 1.8.0 build, upgrade manually once:** quit Goalloom, open the 1.9.3 DMG, and replace Goalloom in Applications. That old ad-hoc signature cannot authorize the Developer ID update. Your workspace and settings stay in place.

## 改进

- **按 Enter 立即保存。** 新建任务不再等待 Jev。已有有效预览时直接创建；结果尚未返回时先保存，随后只补全新任务的时间列和目标关联。列内录入保留已选列和周期，手动修改优先。
- **Jev 1.14 更准确地匹配目标。** 按候选的行动与成果判断关联，保留独立上级、去除重复祖先，并将 URL 作为输入数据处理。创建和自动补全仍为一次撤销，也支持电脑之间的加密同步。
- **同步空闲时减少请求。** 状态不变时不再重复读取成员信息和操作记录；后台连接正常时逐步降低检查频率，回到应用后立即检查。上传重试或等待期间仍可下载，待发送修改会保留。
- **统一应用控件。** 首次配置、设置、任务菜单、起草和复盘共用按钮、输入框、选择控件与布局规则，覆盖全部五种语言。

## 升级

1.9.0–1.9.2 用户可在「设置 → 关于」更新，或覆盖安装。工作区格式升至 v11；升级 v8–v10 工作区前，Goalloom 会先创建并校验保护备份，任务、设置和历史会保留。更早格式仍沿用明确确认的恢复流程。旧版应用不能读取 v11 工作区；如需回退，请使用升级前的保护备份。

macOS 凭据继续通过非交互钥匙串访问，包括首次使用和恢复已有凭据。无法读取的凭据保留加密内容，本地看板继续可用。macOS 安装包通过 Developer ID 签名和 Apple 公证；Windows 安装包仍未签名。

**仍使用公开版 macOS 1.8.0 时，请手动升级一次：** 退出 Goalloom，打开 1.9.3 的 DMG，把 Goalloom 拖进「应用程序」并替换旧版。旧版的 ad-hoc 签名无法通过内置更新切换到 Developer ID 签名，工作区和设置会保留。
