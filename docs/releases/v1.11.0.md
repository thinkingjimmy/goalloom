# Goalloom 1.11.0 for macOS

## English

- **A clearer first start.** Configure your calendar and direction beside a persistent preview of the board, then start local work or connect an account when you choose.
- **Notifications that stay readable.** Messages use a stacked notification layout, with each action kept with its message.
- **Weekly reviews across month boundaries.** A week that spans two months can still open its review and use the current month’s goals.
- **A little variety when you finish.** Completion celebrations can use random emoji while respecting the existing feedback and reduced-motion settings.

For Apple silicon on macOS 14 or later. The official app and DMG are Developer ID signed and notarized. Local work and BYOK remain free; optional Plus keeps the existing account, trial and subscription rules.

This update preserves app identity, user-data paths and workspace format v14. Upgrading an older supported workspace still creates a verified protective backup. Keep your local data and backups. Windows stays on 1.9.10 with its existing installer and update manifest; Windows Plus and the iPhone app are not part of this release.

## 简体中文

- **更清楚的首次开始。** 在持续可见的看板预览旁配置日历与方向，再选择开始本地使用或连接账号。
- **通知更易读。** 消息采用堆叠布局，每条消息保留自己的操作。
- **跨月也能正常周复盘。** 跨越两个月的周可以继续打开复盘，并使用当前月份的目标。
- **完成时多一点变化。** 完成反馈可使用随机表情，并遵守现有反馈与减少动态效果设置。

适用于 Apple 芯片的 macOS 14 及以上系统。正式应用与 DMG 使用 Developer ID 签名并通过公证。本地功能和 BYOK 继续免费；可选 Plus 沿用现有账号、试用与订阅规则。

应用身份、用户数据目录和 v14 工作区格式保持不变。受支持的旧工作区升级时仍会创建并验证保护性备份，请保留本地数据与备份。Windows 仍为 1.9.10，保留现有安装包与更新清单；本次不包含 Windows Plus 或 iPhone 应用。
