# Goalloom 1.9.5

## Improvements

- **Stay signed in between sessions.** Normal app quits, computer restarts and updates retain your sync session. After an explicit sign-out, sign in with Google and enter your sync password to resume automatic sync.
- **macOS sync without Keychain authorization dialogs.** Sync credentials use private application storage with noninteractive access. If an older installation cannot read its saved credentials, sign in with Google and enter the sync password once to restore access. Unavailable storage preserves encrypted data and never opens a system authorization dialog.
- **Reliable first sync across computers.** If you enable sync on an empty computer first, then sign in on the computer containing your tasks, the tasks and calendar reach both computers. Repeated sign-out/sign-in preserves task identities and deletion records without importing the same tasks again.
- **Recovery preserves pending work.** Interrupted uploads retain their original identities. Network restoration resumes sync automatically. An unavailable AI credential store no longer blocks task synchronization.

## Upgrade

Update through Settings → About, or install over the existing app. Version 1.9.5 keeps workspace format v11, the existing application identity and your data directory. Readable saved sessions migrate automatically. If old credentials cannot be read, complete Google sign-in and enter your sync password once; later starts restore the session when secure storage is available.

macOS downloads are Developer ID signed and notarized by Apple. Windows installers remain unsigned. If you still use the published macOS 1.8.0 build, quit Goalloom and manually replace it with 1.9.5 in Applications once. Your workspace and settings are kept.

## 改进

- **重新打开后继续同步。** 正常退出应用、重启电脑和升级会保留同步会话。主动退出账号后，重新完成 Google 登录并输入同步密码，即可恢复自动同步。
- **macOS 同步不再需要钥匙串授权弹窗。** 同步凭据改用应用专属的静默安全存储。旧版安装若无法读取已保存的凭据，可以通过一次 Google 登录和同步密码验证恢复。存储暂时不可用时会保留加密数据，不会打开系统授权弹窗。
- **两台电脑首次汇合更可靠。** 先在空电脑开启同步，再到已有任务的电脑登录，任务和日历即可同步到两台电脑。反复退出、登录会保留任务编号和删除记录，不会重复导入相同任务。
- **恢复时保留待同步修改。** 中断的上传保留原操作编号；恢复网络后自动继续同步。独立 AI 凭据暂时不可用时，不再阻断任务同步。

## 升级

可在「设置 → 关于」更新，或覆盖安装。1.9.5 保持工作区格式 v11、应用身份和原数据目录。可读取的旧会话会自动迁移；若旧凭据无法读取，请完成一次 Google 登录并输入同步密码，安全存储可用后，后续启动会自动恢复会话。

macOS 安装包通过 Developer ID 签名和 Apple 公证；Windows 安装包仍未签名。若仍在使用公开版 macOS 1.8.0，请先退出 Goalloom，再手动用 1.9.5 替换「应用程序」中的旧版一次，工作区与设置会保留。
