# Goalloom 1.12.0 for macOS

## English

- **More time to review.** The previous week's review remains available through the current week. The previous month's review stays available through the current month. Dismissed reminders stay dismissed after restart.
- **More reliable capture.** Jev keeps written dates and task ownership consistent when a suggestion arrives before or after you save. Manual choices keep priority.
- **Clearer deadlines and password entry.** Deadline badges follow your language and appearance. Sync password entry regains focus after background work, while keeping a control you have selected.
- **Paid Plus, without a trial.** Local work and BYOK remain free. Plus cloud services require a verified paid subscription. Task assistance supports rewriting notes.

**Check the workspace format before updating.** This version accepts only workspace and export format v15. It does not upgrade v14 workspaces from 1.11.0 or other older formats. Unsupported databases, backups, exports and saved credentials are refused and kept unchanged. Keep your previous app, local data and backups if you still need an older format. Signing in again does not convert an old workspace or cloud copy.

For Apple silicon on macOS 14 or later. Official macOS files are Developer ID signed and notarized. App identity and user-data paths stay the same. Windows stays on 1.9.10 with its existing files and update metadata. This release does not publish the iPhone app or deploy hosted services.

## 简体中文

- **复盘有更充足的时间。** 上周复盘在本周内持续可用，上月复盘在本月内持续可用。关闭后的提醒在重启后仍保持关闭。
- **输入更可靠。** 无论建议在保存前还是保存后返回，Jev 都会一致处理写明的日期和任务归属。手动选择保持优先。
- **截止日期和密码输入更清楚。** 截止日期标记跟随界面语言和外观。后台操作结束后，同步密码输入恢复焦点，并保留你已选择的控件。
- **Plus 采用付费订阅，无试用。** 本地功能和 BYOK 继续免费。Plus 云服务需要已验证的付费订阅。任务辅助支持改写笔记。

**更新前请核对工作区格式。** 本版只接受 v15 工作区及导出格式，不会升级 1.11.0 的 v14 工作区或其他旧格式。不支持的数据库、备份、导出文件和已存凭据会被拒绝读取，并保持原样。如需继续使用旧格式，请保留原版应用、本地数据和备份。重新登录不会转换旧工作区或云端副本。

适用于 Apple 芯片的 macOS 14 及以上系统。正式 macOS 文件使用 Developer ID 签名并通过公证。应用身份和用户数据目录保持不变。Windows 仍为 1.9.10，保留现有文件和更新清单。本次不发布 iPhone 应用，也不部署云端服务。

## 日本語

- **振り返りの時間を確保。** 先週の振り返りは今週中、先月の振り返りは今月中に利用できます。閉じた通知は再起動後も閉じたままです。
- **安定したタスク入力。** 保存前でも保存後でも、Jev は明記された日付とタスクの所属を同じように扱います。手動の選択を優先します。
- **期限とパスワード入力を改善。** 期限の表示は言語と外観の設定に従います。バックグラウンド処理後に同期パスワードの入力へフォーカスが戻ります。別のコントロールを選択した場合は、その選択を保持します。

**更新前にワークスペース形式を確認してください。** このバージョンは v15 のワークスペースとエクスポート形式のみを受け付けます。1.11.0 の v14 や、それ以前の形式は更新しません。非対応のデータベース、バックアップ、エクスポート、保存済み認証情報は変更せず、読み込みを拒否します。古い形式が必要な場合は、以前のアプリ、ローカルデータ、バックアップを保持してください。再ログインしても古いワークスペースやクラウドコピーは変換されません。

Apple シリコン搭載の macOS 14 以降に対応します。正式な macOS ファイルは Developer ID で署名され、公証済みです。アプリの識別情報とデータフォルダは変わりません。Windows は既存のファイルと更新情報を使う 1.9.10 のままです。iPhone アプリの公開とホストサービスのデプロイは含みません。

## Español

- **Más tiempo para revisar.** La revisión de la semana anterior sigue disponible durante la semana actual. La del mes anterior sigue disponible durante el mes actual. Los avisos descartados permanecen cerrados después de reiniciar.

- **Plus de pago, sin prueba.** El trabajo local y BYOK siguen siendo gratuitos. Los servicios de Plus requieren una suscripción de pago verificada. La asistencia de tareas permite reescribir notas.

Conserva la aplicación anterior, los datos locales y las copias si necesitas un formato antiguo. Volver a iniciar sesión no convierte un espacio ni una copia antigua en la nube.

Para Apple Silicon con macOS 14 o posterior. Los archivos oficiales de macOS están firmados con Developer ID y notarizados. Se mantienen la identidad de la aplicación y las rutas de datos.
