# Goalloom 1.9.0

**macOS: the published 1.8.0 build needs one manual upgrade.** Quit Goalloom, open the 1.9.0 DMG, and replace Goalloom in Applications. Your workspace and settings stay in place. The 1.8.0 Mac build uses an ad-hoc signature that cannot authorize the new Developer ID signature.

**macOS：公开版 1.8.0 需手动升级一次。** 退出 Goalloom，打开 1.9.0 的 DMG，把 Goalloom 拖进「应用程序」并替换旧版。工作区和设置会保留。1.8.0 的 Mac 安装包使用 ad-hoc 签名，无法通过内置更新切换到本次 Developer ID 签名。

## What's new

- **Completed tasks stay in place.** Completing or reopening a task keeps its position on the board. To use a separate completed group, turn on “Collapse completed tasks” in Settings → Board. Nested tasks stay together. This preference also syncs between computers.
- **Arrange tasks your way.** Manual sorting works across goal groups. Optional automatic placement puts a new task beside tasks with the same goal, without moving existing tasks. “Arrange by parent” sorts just the selected column once and can be undone.
- **Your settings follow you.** When sync is enabled, appearance, language, shortcuts, board preferences and saved AI provider keys sync between computers. Keys are encrypted before transfer and stored in each computer’s system keychain. Workspace files, exports and backups do not contain the keys.

## Improvements and fixes

- Dragging onto the middle of a row makes a subtask; the row edges sort tasks. Drop indicators match the saved position. Long titles wrap in the drag preview.
- Global capture grows with its text. Nesting saves quietly, with keyboard undo still available. The “Next step” action appears when its row is hovered or focused.
- Google sign-in brings the desktop window back to the front.
- Arranging a column returns keyboard focus to its menu button. Narrow columns keep English week dates complete.
- JSON import keeps combined goal-link and placement changes valid for undo.
- macOS downloads are now Developer ID signed and notarized by Apple. Drag Goalloom into Applications and open it normally. Windows installers remain unsigned.

## Upgrade

Installing over 1.8.0 keeps your workspace and settings. Follow the manual Mac upgrade above; Windows keeps its existing update and installer paths. This release keeps workspace schema v10. Sync remains optional. These downloads are for macOS 14+ on Apple Silicon and Windows 11 x64; a mobile release is not included.

## 更新说明

- **完成任务后留在原位。** 完成或重新打开任务时，看板中的位置保持不变。若需要独立的已完成分组，可在「设置 → 看板」开启「折叠已完成任务」。二级任务保持整组显示，这项偏好也会在电脑之间同步。
- **按自己的顺序安排任务。** 可以跨目标分组自由排序。可选的自动放置会把新任务放到相同上级的任务旁边，不移动已有任务。「按上级整理」只整理所选列一次，并支持撤销。
- **设置跟随你。** 开启同步后，外观、语言、快捷键、看板偏好和已保存的 AI 服务 Key 会在电脑之间同步。Key 在传输前加密，并保存在各台电脑的系统钥匙串中。工作区文件、导出和备份不包含 Key。

## 改善与修复

- 拖到任务行中部可设为二级任务，拖到行边缘可排序。插入提示与保存后的位置一致，拖拽预览中的长标题会自动换行。
- 全局新建窗口随文字增高。设为二级任务后安静保存，仍可用键盘撤销。「下一步」在悬停或聚焦任务行时显示。
- Google 登录完成后，桌面窗口会回到前台。
- 按上级整理后，键盘焦点回到列菜单按钮。窄列中的英文周日期保持完整。
- JSON 导入保留关联与位置同时变更的撤销记录。
- macOS 安装包现已通过 Developer ID 签名和 Apple 公证。拖进「应用程序」后即可正常打开。Windows 安装包仍未签名。

## 升级

从 1.8.0 覆盖安装可保留工作区和设置；macOS 请按本文开头的步骤手动升级一次，Windows 保留现有更新和安装方式。工作区格式保持 v10，同步仍可选。此次发布提供 macOS 14+ Apple Silicon 和 Windows 11 x64 安装包，不包含移动版。
