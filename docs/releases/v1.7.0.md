# Goalloom 1.7.0

Desktop release notes for the version after 1.6.0. Installers, update feeds and SHA256SUMS are not attached to this file. The release stays pending until those assets are published.

## Upgrade

**From 1.6.0 you can upgrade in place.** Goalloom 1.7.0 uses workspace schema v10. Opening a 1.6.0 workspace (schema v8) first creates and verifies an automatic protective backup, then upgrades that same workspace file. If the backup or the upgrade fails, the original file stays on the old version. Tasks, notes, history, calendar and appearance are kept.

**1.6.0 可直接升级。** 1.7.0 使用工作区格式 v10。打开 1.6.0 工作区（schema v8）时，会先自动创建并校验保护备份，再原地升级同一份工作区文件。备份或升级失败时，原文件保持旧版本。任务、说明、历史、日历和外观都会保留。

A v10 workspace cannot be opened by 1.6.0 or earlier. To return to the pre-upgrade data, restore the protective copy from the new version under Settings & data → Backups. Keeping a JSON export before you update is still a good idea.

v10 工作区不能再用 1.6.0 或更早版本打开。若要回到升级前的数据，请在新版本的「设置与数据 → 备份」里恢复保护副本。升级前仍建议自己留一份 JSON 导出。

**1.5.0 and earlier** still use the existing confirmed upgrade: the app creates and verifies a protective copy, then asks you to confirm before it replaces the workspace. Cancelling keeps the original file. The upgraded workspace is schema v10.

**1.5.0 及更早版本**仍走现有的确认升级：先创建并校验保护副本，再经明确确认后替换工作区。取消则保留原文件。升级后的工作区同样是 schema v10。

## What's new

- **Nest a task under another.** Drop a task on the middle of a top-level row, or choose “Make a subtask” from its menu, to place it one level under that task. The row edges still reorder. A nested task is indented 24px. Only two levels are supported: a task that already has subtasks cannot be nested, and a subtask cannot take its own subtasks. The same actions are available from the keyboard menu, in Chinese, English, Japanese, Spanish and French.
- **Subtasks follow the parent’s goals and color.** A nested task shows the goal links and flow color of its top-level task. Change those on the parent. The subtask keeps its own title, notes, dates and completion. Later can nest tasks, and Later still has no flow color or new goal links.
- **Make a subtask independent.** “Make independent” lifts the task out of the group and keeps the goals and color it was showing. Deleting or unnesting the parent does the same for its children. A colored parent with no goal links leaves those children without a color.
- **Move the group together.** Moving a top-level task, or letting its period roll forward, moves the live subtasks with it and does not change their completion times. If any unfinished member is held in the current period, the group does not roll forward automatically.

## Improvements

- **Next step stays a labelled pill.** On a filtered flow, a task with no child shows the “Next step” pill centered on the row. The hollow ring is gone. Pointer preview, keyboard focus and drafting use the same control.
- **Write in the empty column.** On an empty planning column, “Write my own” opens the same inline entry as the column +, in the period you are looking at. Drafting from existing parents still opens the batch window.
- **Last week’s review stays for the week.** The weekly review follows the workspace week start and time zone. It appears when the new week starts, stays until you finish or dismiss it, and is replaced next week. Closing the card hides only that reminder: it does not mark the review done or change tasks. Unfinished items from that review default to this week on any day of the week. The monthly review still uses the last day of the month and the first day of the next month.

## Not in this release

**There are no accounts and no cloud sync.** You still use a local workspace, with no sign-in. The repository contains internal groundwork for a later sync protocol; that work is not a feature in 1.7.0.

## 更新说明

- **把任务收成两级。** 拖到一级任务行的中部，或在菜单里选「设为二级 todo」，即可把它放进该任务下面。行的上下边缘仍用来排序。二级任务缩进 24px。只支持两层：已有二级任务的一级任务不能再被嵌套，二级任务也不能再收子项。键盘菜单提供同样的操作，中文、英文、日文、西班牙文和法文都有对应文案。
- **二级任务跟随所属任务的上级和颜色。** 嵌套后的任务显示所属任务当前的目标关联和流程颜色，这些要在所属任务上修改。二级任务自己的标题、说明、日期和完成状态保持独立。Later 可以嵌套，Later 仍然没有流程颜色，也不能新建目标关联。
- **恢复为一级。** 「恢复为一级」会把任务移出分组，并保留它当时显示的上级和颜色。取消嵌套或删除所属任务时，它的二级任务同样会带上这些继承来的上级。只有颜色、没有目标关联的所属任务，拆开后的二级任务不再带颜色。
- **整组一起移动。** 移动一级任务，或它所在的周期顺延时，未删除的二级任务一起移动，完成时间不变。组里任一未完成任务被留在当前周期时，整组不会自动顺延。
- **「下一步」始终是带文字的胶囊。** 筛选某条流程时，没有下级的任务在整行中间显示「＋ 下一步」，不再出现空心圆。圆点预览、键盘聚焦和起草中使用同一个按钮。
- **空列里直接自己写。** 空的规划列上，「自己写」与列头 ＋ 相同，在当前列打开行内新建，并写入正在看的周期。从已有上级起草仍打开批量窗口。
- **上周复盘保留整整一周。** 周回顾按工作区的周起始日和时区出现：新的一周开始时出现刚结束那一周的回顾，本周内一直保留，完成或关闭后才消失，下周换成新的上周回顾。关闭卡片只隐藏这一次提醒，不记为已复盘，也不改任务。这次回顾里的未完成项，在本周任何一天都默认移入本周。月复盘仍是月末最后一天和次月第一天。

## 本版本不包含

**没有账号，也没有云同步。** 工作区仍在本机，不需要登录。仓库里有面向以后同步协议的内部准备，那不是 1.7.0 里可以使用的功能。
