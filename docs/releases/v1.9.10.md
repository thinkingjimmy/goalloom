# Goalloom 1.9.10

## Improvements

- **Sign in with Apple.** Choose Apple or Google when you first open Goalloom or in Settings > Sync. Both use the existing encrypted workspace and sync-password flow. You can cancel authorization, retry a failed attempt and see which provider is waiting for the browser.
- **Drag a subtask back to the main list.** Drop it at the full-width insertion line to make it independent at that position. Its inherited goal links are retained. One undo restores its previous level and order.
- **Clearer details.** AI service settings use compact icon actions. Subtask connectors keep their rounded corners.

## Update

Workspace format remains v11. Updates preserve the app identity, local data location, tasks and settings. macOS downloads are Developer ID signed and notarized by Apple; Windows installers remain unsigned.

Use the same account and sync password on each computer. Different Apple and Google email addresses can identify separate accounts. This release does not include a mobile app.

If updating from 1.9.7 or earlier, also follow the production-sync transition instructions in the [1.9.8 release notes](https://github.com/thinkingjimmy/goalloom/releases/tag/v1.9.8). The published macOS 1.8.0 build requires one manual replacement in Applications.

## 改进

- **使用 Apple 登录。** 首次打开 Goalloom 或进入「设置 > 同步」时，可选择 Apple 或 Google。两种方式沿用已有的加密工作区和同步密码流程。授权可以取消，失败后可以重试，并显示当前等待浏览器返回的登录方式。
- **把子任务拖回一级列表。** 将子任务放到全宽插入线处，即可在该位置恢复为独立任务，并保留继承的目标关联。一次撤销可恢复原来的层级和顺序。
- **细节更清楚。** AI 服务设置使用紧凑的图标操作；子任务连线保留圆角。

## 更新

工作区格式保持 v11。升级保留应用身份、本地数据目录、任务和设置。macOS 安装包使用 Developer ID 签名并通过 Apple 公证；Windows 安装包仍未签名。

请在各台电脑上使用同一账号和同步密码。Apple 与 Google 使用不同邮箱时，可能对应不同账号。本次发布不包含移动端应用。

从 1.9.7 或更早版本升级时，还需遵循 [1.9.8 发布说明](https://github.com/thinkingjimmy/goalloom/releases/tag/v1.9.8)中的生产同步迁入步骤。公开版 macOS 1.8.0 需手动替换「应用程序」中的旧版一次。
