# Goalloom · 技术方案与开发 TODO

v0.4 · 2026-09-22。产品行为以 [PRD](PRD.md) 为准。本文件合并架构、图标接入、开发清单和验收；所有应用任务 / 测试均未完成。勾选需有实现与测试结果，不以文档或浏览器截图代替。

## 1. 工程约束

**结构：** `src/main`（业务 / 数据）、`src/preload`（桥接）、`src/renderer`（React UI）、`src/shared/contracts`、`tests`。一个应用、一个权威写入通道，首版单实例 / 单工作窗口。不搭多框架、云同步或完整事件溯源平台。

**安全：** renderer → 有限 `window.goalloom` API → contextBridge / preload → 经验证的 main 命令 → SQLite。要求 `contextIsolation=true`、`sandbox=true`、`nodeIntegration=false`；验证来源、参数、版本、返回 DTO；只加载本地资源，限制导航、新窗口、权限和外链协议，不暴露原始 IPC、SQL、任意文件路径或 shell。用户文本不执行脚本，日志不含正文 / 凭据。

**依赖：** 在实际 Electron 内嵌 Node 与安装包验证 SQLite 驱动；原生模块检查 ABI、CPU、rebuild 与资源打包。版本在 M1 锁定，不把宿主 Node 或任意 latest 当兼容证据。Vite 构建，electron-vite、dnd-kit 和测试 runner 作为待验证工具。大查询 / 导入若阻塞主进程，移到受控存储 worker，不放松安全边界。预览 mock 明示不持久化，正式构建缺存储直接报错。

**图标：** `@hugeicons/react` + `@hugeicons/core-free-icons`；共享轻量入口放 `src/renderer/components/icons/`，仅显式导入实际存在的图标，不整库扫描。默认 Stroke Rounded、线宽1.5、工具栏20px / 行内16px / 空状态24–32px、`currentColor`；这些是设计默认。审查新增 shadcn 内部图标和 SVG 选择器，保持 ref、焦点、键盘、命中区域与可访问名称；无运行时 CDN / SVG / 字体请求，无未经批准 Pro，保留许可证。缺合适免费图标先用文字，不引入第二套库。

## 2. 数据与事务

具体 DDL 在首次生产迁移前冻结；最低实体如下，不预建进度、账号或团队表。

| 实体 | 必要信息 / 约束 |
| --- | --- |
| items | 稳定 ID、类型、标题 / 说明、颜色、状态、due_date、completed_at、归档 / 删除时间、版本及创建 / 修改时间；标题非空，状态与完成时间一致 |
| planning_periods / item_placements | 尺度、日历起止 / 排他结束、时区及固定 UTC 边界；每项唯一位置、排序和版本；Later 周期为空，其他尺度与周期匹配；`auto_hold_period_id`保存撤销抑制 |
| item_relations | parent / child、失效标记；端点有效，活跃边去重，事务内防自关联 / 防环；基数待 D06 |
| settings / rollover_policies | 工作区时区、周起始日、周期锚点；尺度策略、版本、生效源周期及`rollover_paused_after_restore`；Later 无策略 |
| operations / item_events | 操作 / 批次 ID、来源、请求摘要、结果；事件 ID、操作内唯一序号、全局 seq、实际时间、类型、payload版本、有限前后值、undo引用 |
| schema_migrations | 迁移版本与执行时间，失败不提升版本 |

**写入规则：** 创建条目 / 位置 / 初始关系 / 创建事件同事务；后续当前表、关键事件和操作回执也必须全成或全败。operationId同请求重试返回原结果，不同请求冲突。前端预检只改善体验，main / 数据库才是权威；手动命令检查版本，系统批次在统一写通道重新读取候选。启用外键、合法日期和唯一约束。

**事件边界：** 从第一笔写入记录创建 / baseline、移动、顺延、完成 / 重开 / 取消、归档 / 解除归档、删除 / 恢复及撤销。只存计划、状态、可见性、版本和撤销所需排序 / hold，不存正文版本。标题 / 说明 / 关系编辑与同周期排序可只增加相关版本，不制造顺延事件。所有实际修改递增相应版本；删除保留历史身份，不物理级联事件。

**历史查询：** 当前看板直接读实体表；历史按曾明确进入该周期的ID去重，用固定结束UTC边界前最后状态推导期末，再分开显示后续结果。按 item / seq、operation / index及来源 / 目标周期索引，不全库重放或扫描JSON。seq稳定同时间事件；边界时刻属于下一周期，时钟回拨标注不确定，不伪造时刻。baseline之前未知，不能用当前状态回填。

**导入链校验：** 连续性白名单为 horizon、periodId、status、completedAt、archivedAt、deletedAt；验证事件类型、身份、日期、序号、引用、undo与末尾业务状态和当前表一致。版本允许合法跳号，排序 / 邻居允许未记录变化，不能要求整份 before / after JSON 全等；hold另按撤销 / 策略约束验证。安全撤销仍严格匹配当前 item / placement 版本与原目标位置，不能借导入宽容覆盖新编辑。

**日历 / 顺延：** 按工作区日历计算日 / 周 / 月，不用固定24小时或90天；周key含起始日期，三个月按原锚点+3n月。修改时区 / 周起始日先预览，不重算历史边界。统一 reconcile 在启动 / 唤醒 / 前台 / 日期边界触发，一轮一个观测时刻；只选已结束、有效todo、auto策略、生效范围内、无本周期hold且非恢复暂停的项。不能用“今天执行过”跳过后来出现的候选。

**顺延 / 撤销：** 按目标周期原子分批，稳定追加排序，写每项事件与批次回执，成功才通知。移动中只改变临时UI，失败回滚并保留输入；排序用可重排的稳定键。批次撤销先预览再事务复核，跳过后改项；恢复相对邻居，不覆盖整列，追加反向事件且每事件最多撤销一次。hold取撤销执行时的当前周期并落盘；下周期不再匹配，手动移位清除。

**导出 / 恢复：** JSON带schemaVersion / exportedAt及全部上述业务实体、设置、事件和回执，保留ID、seq、时序、生效边界与undo / hold。大小限制→schema / 字段 / 日期 / 图 / 链校验→预览确认→一致性备份→原子替换→完整性检查。备份覆盖已提交WAL内容，不随意复制活跃主文件。未知schema、重复 / 悬空引用、非法图或真不连续业务链拒绝，失败保留原库。恢复成功落盘暂停自动补处理，确认才解除；旧数据无历史从真实导入时建baseline，已有历史不改成导入时刻。缺旧策略先保留旧积压手动处理，新当前周期采用默认，预览说明。

## 3. 分阶段开发与验收

### M0 · 只确认剩余边界

### M1 · 最小 Electron 双平台闭环

- [ ] 建立 React / TypeScript strict / Vite / shadcn / Tailwind / Electron 三入口和受控IPC，锁定构建、打包、驱动与测试依赖。
- [ ] 接入 Hugeicons 共享入口，检查 shadcn 内部残留、许可证和打包后离线图标。
- [ ] 做两列录入 / 拖拽、关联选择器、SQLite 保存 / 重启与导入导出文件对话框，在 Mac / Windows 都打包安装。
- [ ] 测中文IME、emoji、剪贴板、空列 / Esc / 键盘、主题 / 缩放 / ref / 焦点；记录实际运行时、CPU、OS、启动 / 内存 / 体积。

通过标准：真实两平台安装闭环，不用浏览器或宿主Node测试代替。可注入测试时钟不暴露到生产。

### M2 · 五列、关联与可靠存储

- [ ] 建立数据表、迁移和日历；录入 / 编辑 / 完成 / 重开 / 取消 / 归档 / 删除 / 恢复与关键事件同事务。
- [ ] 实现一个主位置、独立due_date、稳定排序、跨列移动 / 键盘替代、详情、中文搜索、完成分组、主题和窄窗口布局。
- [ ] 实现关系搜索、拆解、真实ID标签、+N折叠、定位、上级 / 下级、选中高亮及可见端点连线；不增加进度或状态传播。
- [ ] 测去重 / 防环 / 并发、解除不删任务、删除影响预览与冲突恢复；按D06补多父独立完成或单父原子替换用例。
- [ ] 测断网创建→移动→完成→重启；写入失败 / 响应丢失重试无半个操作、重复任务或重复事件，IME不误提交，同名不合并。

通过标准：三个月→月→周→今天的独立条目可追溯，移动不复制或丢关系，完成只改自己。

### M3 · 历史与往期未完成

- [ ] 实现按列历史 / 返回当前、只读引用、空周期 / 起点边界、当前内容说明；会话历史不强跳，重启回当前，禁止历史 / 未来排期。
- [ ] 实现期末状态与后来结果分开、成员去重、全局完成按真实日期；不把日任务隐式归入月计划或把当前连线接到历史行。
- [ ] 实现所有策略下的往期入口、原周期与独立计数、稳定分组及批量安排当前 / Later；支持单项完成 / 取消和暂不处理。
- [ ] 测9月计划10月完成、先完成后重开、取消 / 归档 / 删除后恢复、旧任务直接完成、同周期往返；历史不被后续状态覆盖且没有虚假计划。
- [ ] 测自动策略下的撤销hold、自动失败、设置生效前积压、恢复暂停均可在当前列找到；翻页不改实体或其他列。

### M4 · 顺延、撤销与完整恢复

- [ ] 按PRD默认实现分尺度设置与生效边界，统一reconcile、原子批次、来源标记 / 查看 / 撤销，不级联目标关系。
- [ ] 实现冲突预览 / 版本复核 / 部分跳过、反向事件和持久化hold；0项和失败不能提示成功，重启不立即重做撤销过的顺延。
- [ ] 实现全量JSON导出恢复、确认 / 备份 / 暂停、无历史baseline和迁移失败恢复；不做智能合并。
- [ ] 通过下面的回归场景；测试结果写入PR / commit说明，不新增重复规格文件。

| 场景 | 必须验证 |
| --- | --- |
| 默认值与策略切换 | 日auto、周月manual可改、周期manual、Later无；开启不清旧积压，关闭不倒退，再启用重设边界 |
| 多来源与排除项 | 当前排序保留，按来源追加；完成 / 取消 / 归档 / 删除不顺延，不修改due_date / 关系 / 状态 |
| 长期退出与反复触发 | 9→11仅实际一次，无虚假10月；重启 / 唤醒 / 多入口 / 响应丢失不重复，不漏后来新候选 |
| 顺延与手动完成竞争 | 串行提交顺序真实；先完成不顺延，先顺延后完成保留两次事件；失败全回滚 |
| 撤销与冲突 | 编辑 / 排序 / 完成 / 移动后跳过；未改项恢复，一事件至多一次；旧批次取执行时当前周期hold |
| 撤销后的生命周期 | 重启仍在往期入口；下周期可按策略处理，手动移位解除旧hold，不永久冻结 |
| 日历边界 | 月底 / 闰年 / 跨年周 / 夏令时 / 时区变更；午夜事件属新周期，时钟回拨不捏造历史 |
| 合法导出恢复 | 创建→改标题 / 说明 / 关系→排序→完成→导出恢复成功，允许版本跳号，保留业务历史 |
| 非法恢复与故障 | 真非法业务链、循环图、重复 / 悬空引用、未知schema拒绝；磁盘满 / 中断 / WAL备份可恢复，无部分覆盖 |
| 历史与恢复暂停 | 保留原事件身份 / 时序及undo；无历史不回填；确认后才补处理，重启不绕过，往期入口可操作 |
