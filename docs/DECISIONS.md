## 本轮采用的实施细化

历史与顺延完整规则见 [HISTORY_AND_ROLLOVER.md](HISTORY_AND_ROLLOVER.md)。用户批准的是产品方向，以下字段 / 冲突细节是将方向落成可实施规格，不增加新的范围确认阻塞：

- 设置启用从当前周期起生效，之前积压不追溯自动搬动；关闭不撤回已发生的顺延。
- 自动顺延以原子批次记录；撤销只恢复未被后续修改的项，追加反向事件并在本周期内抑制再次自动顺延。
- 历史页按曾明确安排到该尺度 / 周期的任务去重，不把所有日任务隐式复制为月计划。
- 导出包含关键事件、策略、批次和抑制信息；恢复后自动补处理暂停至用户确认。
- 历史使用当前标题 / 内容时明确标注，缺乏早期事件时显示历史不完整，不伪造快照。
- 当前表直接服务当前看板；小型关键事件表只用于历史、顺延和撤销，不建设完整事件溯源平台。

D03继续采用独立完成、无百分比 / 权重 / KR的简化MVP；引用刷新是同一实体显示，不是进度传播。
