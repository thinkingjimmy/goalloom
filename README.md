# Goalloom

**把三个月的方向，连接到今天的行动。**  
*From goals to today.*

Goalloom 是融合时间看板与目标关联的个人 Todo：

```text
Later → 3个月 → 本月 → 本周 → 今天
```

时间列回答「什么时候做」，关联回答「为什么做」。移动保留同一个条目；拆解产生独立条目。

## 首版技术路线

**Electron + React + TypeScript + Vite + shadcn/ui + Tailwind CSS + SQLite。**

Electron 为用户已确认选型；具体版本、SQLite 驱动和打包工具在 M1 做双平台验证并锁定。Tauri / QuickGUI 仅保留在历史评估中，不建立第二套正式工程。

## 历史与顺延默认规则

| 列 | 周期结束后的默认处理 | 首版设置 |
| --- | --- | --- |
| 今天 | 自动顺延到新的当天 | 可改为手动安排 |
| 本周 | 放入「往期未完成」 | 可开启自动顺延 |
| 本月 | 放入「往期未完成」 | 可开启自动顺延 |
| 3个月 | 放入「往期未完成」，重新确认方向 | 首版固定手动安排 |
| Later | 不处理 | 无周期 |

过去能回看，未完成不会消失。历史记录不是第二个主位置；顺延不改变截止日期、目标关联或完成状态。首版不自动归档或删除长期未完成事项，也不做完整历史版本恢复。

## 实施顺序与权限

先验证最小 Electron 双平台闭环，再开发五列与数据写入、关联、历史和顺延。关键事件从第一版数据写入时就记录，不等到做历史页面才补造过去。

两张参考截图仅用于私人设计讨论，不把其中的真实任务写进公开示例或遥测。没有授权开源、公开分发、采购或 DNS 更改。所有应用任务必须在实现并完成对应测试后才能勾选。
